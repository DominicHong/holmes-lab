# 策略一C：双均线趋势跟踪 + 量能过滤 + ATR 量能自适应止损（VolFilteredMaCross）

- **标的**：黄金ETF 518880.SH
- **数据频率**：日 K 线（收盘价 + 成交量）
- **版本**：v1.0.1（整理日期 2026-09-15；本版仅修复代码块语法，策略内容与 v1.0 一致）
- **前身策略**：策略一B（MaCrossTrailingStop）的量能增强版
- **一句话概括**：均线定方向，量能定仓位，量价背离与天量定止损松紧，量能触发再入场。

***

## 1. 设计思路

在纯趋势跟踪系统中，成交量信息价值最高的三个应用位置（按优先级排序）：

| 优先级 | 模块    | 作用                               |
| --- | ----- | -------------------------------- |
| ①   | 出场风控  | 量价背离 / 天量时收紧 ATR 止损，锁住利润、防趋势末端回吐 |
| ②   | 再入场节流 | 止损后不立即反手，用量能信号确认后再进场，过滤连环止损      |
| ③   | 入场降档  | 量能不佳时降仓位而非放弃入场，避免错过缩量慢牛          |

## 2. 设计前提：黄金 ETF 量能的三个特性

1. **份额长期扩容**：518880 绝对成交量逐年抬升，任何固定手数阈值都会失真 → 全部使用**相对量**（量比、量能均线比值）。
2. **缩量阴涨是常态**：黄金慢牛中量能往往平平，入场若硬性要求放量会错过主升段 → 量能不佳时**降仓位，不否决入场**。
3. **申赎套利噪音**：ETF 申赎会造成与价格方向无关的单日放量 → 核心判断使用平滑量能（VOL\_MA5 vs VOL\_MA20、OBV 及其均线）。

## 3. 信号周期

- 数据：日 K 线（收盘价 + 成交量）。
- 计算时点：SMA20、SMA60、ATR(14)、VOL\_MA5、VOL\_MA20、OBV、OBV\_SMA20 均在日 K 线收盘后计算与更新。
- 信号判断：仅在当日收盘后进行；满足条件时，**次日开盘执行**。
- 移动止损监测：持仓期内每日收盘后更新。

## 4. 指标体系

### 4.1 基础指标

| 指标                   | 定义                |
| -------------------- | ----------------- |
| SMA20 / SMA60        | 收盘价 20 / 60 日简单均线 |
| ATR(14)              | 14 日平均真实波幅        |
| VOL\_MA5 / VOL\_MA20 | 成交量 5 / 20 日简单均线  |
| 收阳                   | 收盘价 > 当日开盘价       |

### 4.2 OBV（能量潮指标）

OBV 将每日成交量按涨跌方向累计，衡量净资金流向：

- 今日收盘 > 昨日收盘：OBV = 昨日 OBV + 今日成交量
- 今日收盘 < 昨日收盘：OBV = 昨日 OBV − 今日成交量
- 平盘：OBV 不变

注意：OBV 绝对数值无意义（取决于计算起始点），有意义的是其走向及与价格的配合。本策略使用 \*\*OBV\_SMA20（OBV 的 20 日简单均值）\*\*作为其中期趋势参照。

### 4.3 量能状态定义

| 名称   | 定义                                             | 用途           |
| ---- | ---------------------------------------------- | ------------ |
| 量能扩张 | VOL\_MA5 > VOL\_MA20                           | 入场量能健康判据     |
| 量比   | 今日成交量 ÷ VOL\_MA20                              | 再入场触发 / 止损恢复 |
| 放量   | 今日成交量 ≥ 1.5 × VOL\_MA20                        | 止损恢复条件       |
| 天量   | 今日成交量 ≥ 2.5 × VOL\_MA20，且为近 60 日（含当日）最大成交量     | 止损收紧         |
| 量价背离 | 收盘价创持仓期新高，但 VOL\_MA5 < VOL\_MA20 且 OBV 未创持仓期新高 | 止损收紧         |
| 地量异常 | 今日成交量 < 0.2 × VOL\_MA20（如长假前后）                 | 当日量能信号按中性处理  |

## 5. 入场条件

### 5.1 趋势过滤（方向判据，与策略一B一致）

- 今日 SMA20 > SMA60，且今日收盘价 > SMA60 → 趋势向上。
- 死叉（SMA20 ≤ SMA60）不构成空头入场条件，仅用于持仓出场。
- 本策略只做多，SMA20 ≤ SMA60 期间一律空仓等待。

### 5.2 量能健康判定（"或"逻辑）

```
vol_healthy = (VOL_MA5 > VOL_MA20) or (OBV > OBV_SMA20)
```

两个指标度量量能的不同维度（前者看量的绝对水平、反应快；后者看量的方向属性即净流入、更平滑），**任一成立即判定健康**：

| VOL\_MA5 vs VOL\_MA20 | OBV vs OBV\_SMA20 | 判定    | 市场含义                          |
| --------------------- | ----------------- | ----- | ----------------------------- |
| 放量                    | 净流入               | ✅ 健康  | 量价齐升，主升段典型形态                  |
| 放量                    | 无净流入              | ✅ 健康  | 活跃度在但流向模糊（高位换手、申赎放量）          |
| 缩量                    | 净流入               | ✅ 健康  | 缩量阴涨，黄金慢牛最常见形态（OBV 条件专门保护此情形） |
| 缩量                    | 无净流入              | ❌ 不健康 | 量与向皆弱 → 降档                    |

只有最差的一种组合才降档。**量能只调节仓位，不拦截入场**；真正的入场门槛是均线趋势过滤。

### 5.3 首次入场

- 条件：当前无持仓 + 趋势向上 + 不处于止损冷却期。
- 仓位：vol\_healthy → **95%**；否则 → **70%**。
- 执行：次日开盘买入。不必等待新金叉，趋势在场即入场（与策略一B一致）。

### 5.4 趋势再入场（量能触发 + 冷却兜底）

被移动止损打出后**不次日立即反手**，进入 5 个交易日的冷却期，须满足以下任一条件才再入场：

| 触发条件      | 定义                                     | 针对场景           |
| --------- | -------------------------------------- | -------------- |
| a. 放量反攻   | 今日收阳，且量比 ≥ 1.2                         | 多头重新集结，趋势恢复    |
| b. 缩量回踩企稳 | 收盘价距 SMA20 ≤ 1×ATR，未跌破 SMA60，且量比 ≤ 0.8 | 抛压衰竭，回踩健康      |
| c. 冷却兜底   | 冷却期第 5 个交易日收盘，趋势仍向上                    | 防止量能条件长期不满足而踏空 |

再入场仓位同样按 5.2 判定（95% / 70%）。

> 说明：死叉出场不进入冷却期——死叉出场时趋势已向下，重新入场天然需等待趋势再度向上，无连环反手风险。

## 6. 出场条件

### 6.1 初始止损

- 止损价 = 入场价 − 2.0 × ATR(14)。
- ATR 取入场日收盘的 ATR(14)，持仓期间固定，作为移动止损的下限。

### 6.2 移动止损（量能自适应）

止损系数为状态机 state ∈ {NORMAL, DIVERGE, CLIMAX}：

**状态触发（优先级：CLIMAX > DIVERGE > NORMAL 恢复）**

| 状态            | 触发条件            | 止损系数    | 计算基准           |
| ------------- | --------------- | ------- | -------------- |
| NORMAL（基础）    | 默认              | 2.5×ATR | 持仓期最高收盘价       |
| DIVERGE（背离收紧） | 量价背离确认日         | 1.8×ATR | 持仓期最高收盘价       |
| CLIMAX（天量收紧）  | 持仓浮盈 > 5% 后出现天量 | 1.5×ATR | **天量日收盘价（锁定）** |

- **恢复条件**：出现"放量创新高"（量比 ≥ 1.5 且收盘价创持仓期新高）→ 状态恢复 NORMAL，量能重新确认趋势；未恢复前保持收紧。
- 浮盈定义：（今日收盘价 ÷ 入场价 − 1）> 5%。

**刚性规则**

- 止损价 = max(初始止损, 对应基准 − 系数 × ATR(入场日))，**只上移不下移**；收紧后的计算值若低于现有止损价，则不生效。
- 收盘价触及或跌破止损价 → 次日开盘平仓，进入止损冷却期。

### 6.3 趋势出场

- 死叉确认（SMA20 ≤ SMA60）→ 次日开盘平仓，不进入冷却期。

### 6.4 优先级与止盈

- 移动止损优先于死叉。
- 不设固定止盈，不加仓。

## 7. 仓位规则

- 基准仓位：量能健康 95% / 不健康 70%。
- 可选变体——三档评分制（若回测发现二元判断过松或过紧）：

  score = (VOL\_MA5 > VOL\_MA20) + (OBV > OBV\_SMA20)
  position = {2: 0.95, 1: 0.80, 0: 0.70}\[score]

## 9. 边界情况

- 趋势向上期间空仓即入场（受冷却期约束）；SMA20 ≤ SMA60 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 止损收紧（背离 / 天量）只在持仓期内生效，平仓后重置。
- 收紧后的计算值低于现有止损价时不生效（"只上移"原则优先）。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2 × ATR。
- 冷却期计数：止损平仓后的首个交易日为冷却第 1 日，第 5 日收盘触发兜底判断；期满后冷却状态解除。
- 地量异常日（成交量 < 0.2 × VOL\_MA20）：当日量能信号按中性处理，不触发背离 / 天量 / 放量判断。
- 天量需同时满足量能倍数与"近 60 日最大"两个条件，仅倍数达标而未创 60 日新高只算放量。

## 10. 与策略一B的差异对照

| 模块     | 策略一B         | 策略一C                           |
| ------ | ------------ | ------------------------------ |
| 入场方向过滤 | 双均线趋势        | 相同                             |
| 首次入场仓位 | 固定 95%       | 量能健康 95% / 不健康 70%             |
| 止损后再入场 | 趋势向上即立即反手    | 冷却期 + 量能触发 + 5 日兜底             |
| 移动止损系数 | 固定 2.5 × ATR | 状态机：2.5 / 1.8（背离）/ 1.5（天量），可恢复 |
| 趋势出场   | 死叉平仓         | 相同                             |
| 数据需求   | 收盘价          | 收盘价 + 成交量                      |
| 参数数量   | 约 6 个        | 约 16 个（需防过拟合，见下节）              |

## 11. 回测与验证建议（防过拟合）

1. **消融测试**：至少跑 4 组——原策略一B / 仅加出场自适应 / 仅加再入场节流 / 全量版。经验上出场自适应模块胜率提升最稳，入场降档最依赖样本期。
2. **分段验证**：建议 2019–2022 调参、2023–2025 做样本外检验（2024–2025 黄金牛市量能结构剧烈变化，是量能模块的天然压力测试）。
3. **监控三个指标**：
   - 交易次数：若较原策略腰斩，警惕过滤过度；
   - 最大回撤：量能模块应主要改善此指标；
   - 单次连环止损次数：再入场节流模块的直接目标。
4. **裁剪优先级**：新增约 10 个参数，若回测改善不显著，优先砍掉"背离收紧"和"入场降档"，只保留**天量收紧 + 再入场量能触发**这两个性价比最高的模块。
