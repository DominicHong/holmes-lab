# 黄金日频纯多头 CTA 策略逻辑说明书 · 增补篇

> **标的**：回测标的为黄金 ETF 518880.SH  
> **频率**：日频  
> **核心约束**：只能做多，不能做空  
> 本篇为 `au9999_cta.md` 的增补章节，两个策略可独立运行，也可与主文档策略一 ~ 五组合。  
> **策略六**（波动率目标仓位）解决的是"**进多少**"，与主文档七个策略解决"什么时候进"形成互补；  
> **策略七**（MACD + 海龟通道）是与策略一A **相关性最低**的独立趋势腿（ρ = 0.65）。

---

## 统一约定（与主文档一致，两策略共用）

【适用标的与数据】

- 数据：518880.SH 日 K 线（OHLC、成交量、成交额）；策略六、策略七均只需日线数据。
- 日线数据文件：data/518880.SH.csv（OHLC 单位为元/克，volume 单位为千克，amt 单位为亿元）。
- 计算时点：SMA、ATR、MACD、唐奇安通道、已实现波动率等全部指标均在日 K 线收盘后计算与更新，不在盘中抢跑。

【多头约束】

- 只能做多，不能做空。传统 CTA 中的空头信号（死叉、跌破通道下轨、MACD 死叉等）  
  一律只触发「平掉多仓」或「收紧止损」，绝不反向开空。
- 空仓期为合法状态：信号不满足时保持空仓等待，不强制交易。

【执行时点】

- 信号在当日日 K 线收盘后确认；所有买入与卖出均于次日开盘执行。

【仓位模式】（common/constants.py 统一配置）

- 默认 percent\\\_equity：每次开仓金额 = 账户可用现金 × 目标仓位系数，  
  于次日开盘按实际开盘价（含滑点与手续费）折算克数，向下取整到 1 克。
- 策略六的目标仓位系数 ∈ {0, 0.25, 0.50, 0.75, 1.00}（见其「仓位规则」）；  
  策略七的目标仓位系数恒为 0 或 1。
- 不加仓：持仓期间即使再次满足入场条件，也不增加克数。

【跳空处理】

- 隔夜受国际金价与人民币汇率影响可能跳空；  
  出场价位被跳空穿越时，按次日开盘价成交，实际盈亏可能与理论值偏离。

**【回测验证】**

- **默认回测区间** 2018-01-01 \\~ 2026-09-01（含加息周期、降息周期、地缘冲突行情）
- **熊市区间**包括 2014-3-17 \\~ 2015-8-10， 2020-8-7 \\~ 2021-3-5， 2026-1-29 \\~ 2026-7-1
- **震荡市区间**包括 2017-7-21 \\~ 2018-1-17， 2018-5-25 \\~ 2018-10-24，2021-7-8 \\~ 2022-3-4
- **回测策略**应至少包含 Buy-and-Hold，s1a, s1c
- **区间窗口预热**应为"窗口前预热、窗口起点空仓"，确保在窗口起点已经预热完毕。
- **回测指标**包括：收益率、夏普比率、最大回撤、胜率、交易次数
- **成本**：成本按单边手续费 0.02% + 滑点 0.02% 计。
- **趋势策略**在震荡期的连续小亏是固有成本，不应通过过度优化参数规避。

## 策略六：双均线趋势跟踪 + 波动率目标仓位（S1aVolTarget）★ 首推

策略一A 的**仓位层改造版**：入场信号、止损、再入场规则与策略一A **完全一致**，  
唯一变化是把「固定 100% 仓位」换成「波动率目标仓位」。这是本次全部新方案中  
收益 / 风险比改善最稳、参数最不敏感的一个。

【设计思路】

- 主文档现有七个策略解决的是「什么时候进」，但**没有一个解决「进多少」**。  
  固定满仓意味着：波动越大的时候，承担的实际风险越大——而波动放大往往正是趋势末端的特征。
- 波动率目标把风险敞口拉平：波动低时放大仓位，波动高时自动降档，  
  使组合的**日均风险贡献大致恒定**，而不是让风险随市场情绪起伏。
- 改造成本极低：不需要新信号、不需要新数据源，只在下单前乘一个系数。  
  这也意味着**它不会改变信号的择时能力，只改变风险的分布形状**。

【信号周期】

- 数据：日 K 线（收盘价）。
- 指标：SMA30、SMA90、ATR(14)（与策略一A 完全相同）；新增 RV60（60 日已实现波动率，年化）。
- RV60 = 过去 60 日（含当日）日收益率的样本标准差 × √252，**在信号日收盘即可算出，无未来函数**。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤：今日 SMA30 > SMA90，且今日收盘价 > SMA90 → 视为趋势向上。
- 趋势再入场：当前无持仓且趋势向上 → 次日开盘买入，不必等待新的金叉；  
  被止损打出后，只要趋势仍向上即重新入场（与策略一A 一致，本策略未加冷却期）。
- 死叉不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)，ATR 取入场日收盘的 ATR(14)，  
  持仓期间固定，作为移动止损的下限。
- 移动止损：止损价 = max(初始止损, 持仓期最高收盘价 − 2.5 × ATR(入场日))，  
  只上移不下移。收盘价触及或跌破止损价 → 次日开盘平仓。
- 趋势出场：死叉确认（SMA30 ≤ SMA90）→ 次日开盘平仓。
- 执行优先级：移动止损优先于死叉。
- 本策略不设固定止盈，也不设加仓规则。

【仓位规则】——本策略唯一的新增部分

- 目标仓位 = 信号仓位（0 或 1） × 波动率系数 f。
- 波动率系数：`f = min(1.0, 目标年化波动 15% ÷ RV60)`。
- **档位化（抑制换手）**：`f = max(0.25, round(f × 4) ÷ 4)`，即只取 **25% / 50% / 75% / 100%** 四档。  
  网格的作用是避免每日微调仓位导致的无谓交易成本——这是本模块能否实用的关键；  
  未做档位化时该模块的换手成本会吞掉大部分收益改善。
- 下单：次日开盘按「账户权益 × f」折算克数 / 份额（含滑点与手续费），向下取整到 1 克。
- 档位对照示例：

| RV60（年化） | 理论 f = 15% ÷ RV60 | 档位化后 f   | 说明                    |
| -------- | ----------------- | -------- | --------------------- |
| 8%       | 1.88              | 1.00     | 低波动，封顶满仓              |
| 12%      | 1.25              | 1.00     | 低波动，封顶满仓              |
| 20%      | 0.75              | 0.75     | 中波动，降至 3/4 仓          |
| 30%      | 0.50              | 0.50     | 高波动，降至半仓              |
| 60%      | 0.25              | 0.25     | 极端波动（2020-08、2026-01） |
| > 60%    | < 0.25            | **0.25** | 档位下限，不再继续降（防踏空）       |

- **档位下限 25% 而非 0**：黄金长期上行，极端波动期完全清仓会错过 V 型反转；  
  下限设为 1/4 仓是"降低风险"与"保留敞口"的折中。

【参数表】

| 类别 | 参数        | 默认值                     | 敏感性      |
| -- | --------- | ----------------------- | -------- |
| 趋势 | SMA 快 / 慢 | 30 / 90                 | 与策略一A 同  |
| 波幅 | ATR 周期    | 14                      | 同        |
| 止损 | 初始止损      | 2.5 × ATR               | 同        |
| 止损 | 移动止损      | 2.5 × ATR               | 同        |
| 仓位 | 目标年化波动    | 15%                     | 低（见敏感性表） |
| 仓位 | 实现波动窗口    | 60 日                    | 低        |
| 仓位 | 档位网格      | 25%（4 档）                | 中（核心）    |
| 仓位 | 档位下限      | 25%                     | 低        |
| 仓位 | 仓位模式      | percent\\\_equity（系数乘数） | —        |

【边界情况】

- 趋势向上期间空仓即入场；SMA30 ≤ SMA90 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2.5 × ATR。
- **低波动期系数恒为 1**：当 RV60 < 15% 时 f 被封顶到 100%，此时策略六与策略一A 的  
  目标仓位**逐日完全一致**。这解释了回测中 2018 年以前的震荡区间（震荡① / ② / ③）  
  两者收益、回撤、交易次数完全相同——波动率目标模块只在 2020 年后的高波动期才实际生效。
- RV60 在窗口未满 60 日时为空值，此时按 f = 1.0（满仓）处理，不降档。
- 仓位档位变化本身会产生交易：从 100% 调到 75% 是一次部分减仓（计一次成本），  
  但**不触发止损状态机重置**，也不计入胜率统计的完整回合。

- **改善集中在 2026 高位急跌段**：最大回撤由 22.1% 收窄到 **13.3%**，  
  这正是波动率目标的设计目标——急跌期 RV60 迅速抬升，仓位自动降至 25% ~ 50%，  
  相当于在崩盘时"提前减了仓"。同类改善也出现在 2020-08 ~ 2021-03 熊市②。
- **代价**：全区间收益从 226.8% 降到 199.0%（−27.8pp），主要来自牛市段的仓位折让；  
  但回撤降幅（−6.6pp）与 Sharpe 升幅（+0.08）在风险预算上是划算的。
- **仓位分布**（全区间）：平均仓位 38.5%，其中满仓天数占比 31.1%、空仓占比 57.6%  
  （空仓期来自死叉，与策略一A 相同）；扣除空仓期后的持仓日均仓位约 0.91。

## 策略七：双均线趋势跟踪 + MACD + 海龟通道（MacdTurtle，30/15 版）

**趋势通道突破 + 动量过滤**的组合：以唐奇安通道突破定位新趋势的起点，  
用 MACD 柱过滤掉缺乏动量的假突破，用 ATR 移动止损管理持仓，  
并在 MACD 转弱时\*\*收紧（而非直接平仓）\*\*止损。

【设计思路】

- 通道突破类策略（主文档策略二）本质是"用价格创出 N 日新高来确认趋势"，  
  在趋势启动阶段入场最快；缺点是震荡市假突破多、来回止损。
- MACD 提供两个额外信息：**入场端**筛掉"创新高但没有动量"的突破；  
  **出场端**识别动量衰竭，但它天然滞后、直接平仓容易在洗盘中被甩下车。
- 因此本策略把 MACD 放在**出场端收紧紧止损**而非直接平仓：  
  柱翻负时止损系数由 2.5×ATR 收紧到 1.5×ATR——既保护利润，  
  又保留 MACD 重新转强后继续持有的可能。
- 通道参数从海龟原版的 20/10 放大到 **30/15**，是敏感性检验的直接结论（见下）。

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：MACD(12, 26, 9)、唐奇安上轨 Up30（前 30 日最高价）、  
  唐奇安下轨 Dn15（前 15 日最低价）、ATR(14) 均在日 K 线收盘后计算与更新；  
  **通道窗口均不含当日**，即当日只与「昨日及之前」的窗口比较。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【指标体系】

- 唐奇安通道（海龟原版口径）：
  - `Up30(i) = max(high[i-30 .. i-1])`，即前 30 日最高价，不含当日；
  - `Dn15(i) = min(low[i-15 .. i-1])`，即前 15 日最低价，不含当日。
- MACD：`DIF = EMA(12) − EMA(26)`，`DEA = EMA(DIF, 9)`，`HIST = (DIF − DEA) × 2`。
- ATR(14)：Wilder 平滑的真实波幅。
- MACD"转弱"判据：`HIST < 0` **或** `DIF < DEA`（同一条件的两种等价表述，取或）。

【入场条件】

- 突破触发：当前无持仓，且 **当日收盘价 > Up30**（前 30 日最高价）→ 突破候选。
- 动量过滤：且 **当日 HIST > 0**（MACD 柱为正）→ 视为动量确认，允许做多。
- 执行：次日开盘买入，仓位 100%。
- 两条件需**同时满足**；仅突破而 MACD 柱为负 → 视为动量不足的假突破，不交易。
- 收盘价跌破 Dn15 不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)；ATR 取入场日收盘的 ATR(14)，  
  持仓期间固定，作为止损的绝对下限。
- 动态止损（MACD 自适应，**每日重算**）：

| MACD 状态                  | 止损系数    | 计算基准     |
| ------------------------ | ------- | -------- |
| 正常（HIST > 0 且 DIF ≥ DEA） | 2.5×ATR | 持仓期最高收盘价 |
| 转弱（HIST < 0 或 DIF < DEA） | 1.5×ATR | 持仓期最高收盘价 |

止损价 = `max( 初始止损, 持仓期最高收盘价 − 系数 × ATR(入场日) )`。

- 通道出场：当日收盘价 < Dn15（前 15 日最低价）→ 次日开盘平仓。
- 执行优先级：**止损优先于通道出场**（任一触发即次日开盘平仓）。
- 本策略不设固定止盈，不加仓。

【仓位规则】

- 仓位模式见统一约定（默认 percent\\\_equity 100%）；目标仓位恒为 0 或 1。
- 不加仓：持仓期间即使再次突破也不增加克数。

【参数表】

| 类别 | 参数              | 默认值         | 说明                        |
| -- | --------------- | ----------- | ------------------------- |
| 通道 | 入场周期            | 30 日        | 海龟原版为 20，本策略放大至 30（见敏感性）  |
| 通道 | 出场周期            | 15 日        | 海龟原版为 10，本策略放大至 15        |
| 动量 | MACD 快 / 慢 / 信号 | 12 / 26 / 9 | 标准参数，未做优化                 |
| 波幅 | ATR 周期          | 14          | —                         |
| 止损 | 基础（正常）止损        | 2.5 × ATR   | 亦用于初始止损                   |
| 止损 | 收紧（MACD 转弱）止损   | 1.5 × ATR   | 触发条件：HIST < 0 或 DIF < DEA |
| 仓位 | 目标仓位            | 0 / 100%    | —                         |

【边界情况】

- 无持仓且未同时满足「突破 + 动量确认」：不交易。
- 突破 Up30 但 HIST ≤ 0：不交易（无动量的突破不追）。
- 已有持仓：只管理出场，不新开仓位；持仓期间再次突破也不加仓。
- 跌破 Dn15 时若已无持仓：不交易，不反向开空。
- **止损每日重算，不是"只上移"的严格棘轮**：最高收盘价 `highest` 只增不减，  
  但止损系数随 MACD 状态在 2.5 / 1.5 之间切换，因此当 MACD 由弱转强时，  
  止损价会**随系数放宽而下移**（回到 2.5×ATR 的位置）。这一设计是为了给  
  "动量恢复"留出空间，代价是**放弃了一部分已锁定的利润**。
