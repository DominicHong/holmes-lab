## 统一约定（六个策略共用）

【适用标的与数据】

- 数据：518880.SH 日 K 线（OHLC、成交量、成交额）。
- 日线数据文件：data/518880.SH.csv（OHLC 单位为元/克，volume 单位为千克，amt 单位为亿元）。
- 计算时点：所有指标均在日 K 线收盘后计算与更新，不在盘中抢跑。

【多头约束】

- 只能做多，不能做空。传统 CTA 中的空头信号（死叉、跌破下轨、RSI 超买等）
  一律只触发「平掉多仓」，绝不反向开空。
- 空仓期为合法状态：信号不满足时保持空仓等待，不强制交易。

【执行时点】

- 信号在当日日 K 线收盘后确认；所有买入与卖出均于次日执行。

【仓位模式】（common/constants.py 统一配置）

- 默认 percent\_equity：每次开仓金额 = 账户可用现金 × 100%，
  于次日开盘按实际开盘价（含滑点与手续费）折算克数，向下取整到 1 克；
  信号仍于当日收盘确认。
- 不加仓：持仓期间即使再次满足入场条件，也不增加克数。

【跳空处理】

- 隔夜受国际金价与人民币汇率影响可能跳空；
  出场价位被跳空穿越时，按次日开盘价成交，实际盈亏可能与理论值偏离。

【风险基准】

- 默认 percent\_equity 为接近满仓的单笔仓位，不保证该风险上限。

## 策略一A：双均线趋势跟踪 + ATR 移动止损 + 趋势再入场（MaCrossTrailingStop）

【信号周期】

- 数据：日 K 线（收盘价）。
- 计算时点：SMA20、SMA60、ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤：今日 SMA20 > SMA60，且今日收盘价 > SMA60 → 视为趋势向上。
- 趋势再入场：当前无持仓且趋势向上 → 次日开盘买入，不必等待新的金叉；
  被止损打出后，只要趋势仍向上即重新入场。
- 死叉不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2 × ATR(14)，ATR 取入场日收盘的 ATR(14)，
  持仓期间固定，作为移动止损的下限。
- 移动止损：止损价 = max(初始止损, 持仓期最高收盘价 − 2.5 × ATR(入场日))，
  只上移不下移。收盘价触及或跌破止损价 → 次日开盘平仓。
- 趋势出场：死叉确认 → 次日开盘平仓。
- 执行优先级：移动止损优先于死叉。
- 本策略不设固定止盈，也不设加仓规则。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- 不加仓。

【边界情况】

- 趋势向上期间空仓即入场；SMA20 ≤ SMA60 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2×ATR。
- 参数：SMA 20 / 60、ATR 14、初始止损 2.0×ATR、移动止损 2.5×ATR。

## 策略一B：双均线趋势跟踪 + 量能过滤 + ATR 量能自适应止损（VolFilteredMaCross）

策略一A 的量能增强版：均线定方向，量能定仓位，量价背离与天量定止损松紧，量能触发再入场。

【设计思路】成交量信息价值最高的三个应用位置（按优先级排序）：

| 优先级 | 模块    | 作用                               |
| --- | ----- | -------------------------------- |
| ①   | 出场风控  | 量价背离 / 天量时收紧 ATR 止损，锁住利润、防趋势末端回吐 |
| ②   | 再入场节流 | 止损后不立即反手，用量能信号确认后再进场，过滤连环止损      |
| ③   | 入场降档  | 量能不佳时降仓位而非放弃入场，避免错过缩量慢牛          |

【设计前提】黄金 ETF 量能的三个特性：

1. **份额长期扩容**：518880 绝对成交量逐年抬升，任何固定手数阈值都会失真 → 全部使用**相对量**（量比、量能均线比值）。
2. **缩量阴涨是常态**：黄金慢牛中量能往往平平，入场若硬性要求放量会错过主升段 → 量能不佳时**降仓位，不否决入场**。
3. **申赎套利噪音**：ETF 申赎会造成与价格方向无关的单日放量 → 核心判断使用平滑量能（VOL\_MA5 vs VOL\_MA20、OBV 及其均线）。

【信号周期】

- 数据：日 K 线（收盘价 + 成交量）。
- 计算时点：SMA20、SMA60、ATR(14)、VOL\_MA5、VOL\_MA20、OBV、OBV\_SMA20 均在日 K 线收盘后计算与更新。
- 信号判断：仅在当日收盘后进行；满足条件时，次日开盘执行。
- 移动止损监测：持仓期内每日收盘后更新。

【指标体系】

- 基础指标：SMA20 / SMA60（收盘价 20 / 60 日简单均线）、ATR(14)（14 日平均真实波幅）、
  VOL\_MA5 / VOL\_MA20（成交量 5 / 20 日简单均线）、收阳（收盘价 > 当日开盘价）。
- OBV（能量潮）：今日收盘 > 昨日收盘时累加今日成交量，今日收盘 < 昨日收盘时累减，平盘不变。
  OBV 绝对数值无意义（取决于计算起始点），有意义的是其走向及与价格的配合；
  本策略使用 **OBV\_SMA20（OBV 的 20 日简单均值）** 作为其中期趋势参照。
- 量能状态定义：

| 名称   | 定义                                             | 用途           |
| ---- | ---------------------------------------------- | ------------ |
| 量能扩张 | VOL\_MA5 > VOL\_MA20                           | 入场量能健康判据     |
| 量比   | 今日成交量 ÷ VOL\_MA20                              | 再入场触发 / 止损恢复 |
| 放量   | 今日成交量 ≥ 1.5 × VOL\_MA20                        | 止损恢复条件       |
| 天量   | 今日成交量 ≥ 2.5 × VOL\_MA20，且为近 60 日（含当日）最大成交量     | 止损收紧         |
| 量价背离 | 收盘价创持仓期新高，但 VOL\_MA5 < VOL\_MA20 且 OBV 未创持仓期新高 | 止损收紧         |
| 地量异常 | 今日成交量 < 0.2 × VOL\_MA20（如长假前后）                 | 当日量能信号按中性处理  |

【入场条件】

- 趋势过滤（方向判据，与策略一A一致）：今日 SMA20 > SMA60，且今日收盘价 > SMA60 → 趋势向上；
  死叉不构成空头入场条件；本策略只做多，SMA20 ≤ SMA60 期间一律空仓等待。
- 量能健康判定（"或"逻辑）：`vol_healthy = (VOL_MA5 > VOL_MA20) or (OBV > OBV_SMA20)`。
  两个指标度量量能的不同维度（前者看量的绝对水平、反应快；后者看量的方向属性即净流入、更平滑），
  任一成立即判定健康：

| VOL\_MA5 vs VOL\_MA20 | OBV vs OBV\_SMA20 | 判定    | 市场含义                          |
| --------------------- | ----------------- | ----- | ----------------------------- |
| 放量                    | 净流入               | ✅ 健康  | 量价齐升，主升段典型形态                  |
| 放量                    | 无净流入              | ✅ 健康  | 活跃度在但流向模糊（高位换手、申赎放量）          |
| 缩量                    | 净流入               | ✅ 健康  | 缩量阴涨，黄金慢牛最常见形态（OBV 条件专门保护此情形） |
| 缩量                    | 无净流入              | ❌ 不健康 | 量与向皆弱 → 降档                    |

只有最差的一种组合才降档；**量能只调节仓位，不拦截入场**，真正的入场门槛是均线趋势过滤。

- 首次入场：当前无持仓 + 趋势向上 + 不处于止损冷却期；
  仓位 vol\_healthy → **100%**，否则 → **70%**；次日开盘买入，不必等待新金叉（与策略一A一致）。
- 趋势再入场（量能触发 + 冷却兜底）：被移动止损打出后不次日立即反手，
  进入 5 个交易日的冷却期，须满足以下任一条件才再入场：

| 触发条件      | 定义                                     | 针对场景           |
| --------- | -------------------------------------- | -------------- |
| a. 放量反攻   | 今日收阳，且量比 ≥ 1.2                         | 多头重新集结，趋势恢复    |
| b. 缩量回踩企稳 | 收盘价距 SMA20 ≤ 1×ATR，未跌破 SMA60，且量比 ≤ 0.8 | 抛压衰竭，回踩健康      |
| c. 冷却兜底   | 冷却期第 5 个交易日收盘，趋势仍向上                    | 防止量能条件长期不满足而踏空 |

再入场仓位同样按量能健康判定（100% / 70%）。
死叉出场不进入冷却期：死叉出场时趋势已向下，重新入场天然需等待趋势再度向上，无连环反手风险。

【出场条件】

- 初始止损：入场价 − 2.0 × ATR(14)；ATR 取入场日收盘的 ATR(14)，
  持仓期间固定，作为移动止损的下限。
- 移动止损（量能自适应）：止损系数为状态机 state ∈ {NORMAL, DIVERGE, CLIMAX}，
  状态触发优先级 CLIMAX > DIVERGE > NORMAL 恢复：

| 状态            | 触发条件            | 止损系数    | 计算基准           |
| ------------- | --------------- | ------- | -------------- |
| NORMAL（基础）    | 默认              | 2.5×ATR | 持仓期最高收盘价       |
| DIVERGE（背离收紧） | 量价背离确认日         | 1.8×ATR | 持仓期最高收盘价       |
| CLIMAX（天量收紧）  | 持仓浮盈 > 5% 后出现天量 | 1.5×ATR | **天量日收盘价（锁定）** |

- 恢复条件：出现"放量创新高"（量比 ≥ 1.5 且收盘价创持仓期新高）→ 状态恢复 NORMAL，
  量能重新确认趋势；未恢复前保持收紧。
- 浮盈定义：（今日收盘价 ÷ 入场价 − 1）> 5%。
- 止损价 = max(初始止损, 对应基准 − 系数 × ATR(入场日))，**只上移不下移**；
  收紧后的计算值若低于现有止损价，则不生效。
- 收盘价触及或跌破止损价 → 次日开盘平仓，进入止损冷却期。
- 趋势出场：死叉确认（SMA20 ≤ SMA60）→ 次日开盘平仓，不进入冷却期。
- 执行优先级：移动止损优先于死叉；不设固定止盈，不加仓。

【仓位规则】

- 基准仓位：量能健康 100% / 不健康 70%。
- 可选变体——三档评分制（若回测发现二元判断过松或过紧）：
  `score = (VOL_MA5 > VOL_MA20) + (OBV > OBV_SMA20)`，
  仓位 = {2: 100%, 1: 80%, 0: 70%}\[score]。
- 代码内置三个消融开关（默认全开，即本全量版）：
  use\_volume\_stop=False 关闭出场自适应；use\_reentry\_gate=False 关闭再入场节流；
  use\_position\_downgrade=False 关闭入场降档。

【参数表】

| 类别  | 参数             | 默认值                          |
| --- | -------------- | ---------------------------- |
| 趋势  | SMA 快 / 慢      | 20 / 60                      |
| 波幅  | ATR 周期         | 14                           |
| 止损  | 初始止损           | 2.0 × ATR                    |
| 止损  | 基础移动止损（NORMAL） | 2.5 × ATR                    |
| 止损  | 背离收紧（DIVERGE）  | 1.8 × ATR                    |
| 止损  | 天量收紧（CLIMAX）   | 1.5 × ATR                    |
| 止损  | 天量触发浮盈门槛       | 5%                           |
| 量能  | VOL 均线         | 5 / 20                       |
| 量能  | 放量阈值           | 1.5 × VOL\_MA20              |
| 量能  | 天量阈值           | 2.5 × VOL\_MA20（且近 60 日最大）   |
| 量能  | OBV 平滑周期       | 20                           |
| 量能  | 地量阈值           | 0.2 × VOL\_MA20              |
| 再入场 | 放量反攻量比         | 1.2                          |
| 再入场 | 回踩距离           | 1 × ATR                      |
| 再入场 | 冷却兜底期          | 5 交易日                        |
| 仓位  | 基准 / 降档        | 100% / 70%（可选三档 100 / 80 / 70） |

【边界情况】

- 趋势向上期间空仓即入场（受冷却期约束）；SMA20 ≤ SMA60 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 止损收紧（背离 / 天量）只在持仓期内生效，平仓后重置。
- 收紧后的计算值低于现有止损价时不生效（"只上移"原则优先）。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2 × ATR。
- 冷却期计数：止损平仓后的首个交易日为冷却第 1 日，第 5 日收盘触发兜底判断；期满后冷却状态解除。
- 地量异常日（成交量 < 0.2 × VOL\_MA20）：当日量能信号按中性处理，不触发背离 / 天量 / 放量判断。
- 天量需同时满足量能倍数与"近 60 日最大"两个条件，仅倍数达标而未创 60 日新高只算放量。

【与策略一A的差异对照】

| 模块     | 策略一A         | 策略一B                           |
| ------ | ------------ | ------------------------------ |
| 入场方向过滤 | 双均线趋势        | 相同                             |
| 首次入场仓位 | 固定 100%      | 量能健康 100% / 不健康 70%            |
| 止损后再入场 | 趋势向上即立即反手    | 冷却期 + 量能触发 + 5 日兜底             |
| 移动止损系数 | 固定 2.5 × ATR | 状态机：2.5 / 1.8（背离）/ 1.5（天量），可恢复 |
| 趋势出场   | 死叉平仓         | 相同                             |
| 数据需求   | 收盘价          | 收盘价 + 成交量                      |
| 参数数量   | 约 6 个        | 约 16 个（需防过拟合，见下）               |

【回测与验证建议（防过拟合）】

1. **消融测试**：至少跑 4 组——策略一A / 仅加出场自适应 / 仅加再入场节流 / 全量版。
   经验上出场自适应模块胜率提升最稳，入场降档最依赖样本期。
2. **分段验证**：建议 2019–2022 调参、2023–2025 做样本外检验
   （2024–2025 黄金牛市量能结构剧烈变化，是量能模块的天然压力测试）。
3. **监控三个指标**：
   - 交易次数：若较策略一A腰斩，警惕过滤过度；
   - 最大回撤：量能模块应主要改善此指标；
   - 单次连环止损次数：再入场节流模块的直接目标。
4. **裁剪优先级**：新增约 10 个参数，若回测改善不显著，优先砍掉"背离收紧"和"入场降档"，
   只保留**天量收紧 + 再入场量能触发**这两个性价比最高的模块。

## 策略二：唐奇安通道突破（20 日入场 / 10 日出场）（DonchianBreakout）

【信号周期】

- 数据：日 K 线（收盘价、成交量）。
- 计算时点：Upper20（前 20 日最高价）、Lower10（前 10 日最低价）、
  前 20 日平均成交量、ATR(14) 均在日 K 线收盘后计算与更新；
  通道与均量窗口均不含当日，即当日只与「昨日及之前」的窗口比较。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 量能过滤（前 20 日均量 × 1.5）：
  - 当日成交量 > 前 20 日（不含当日）平均成交量 × 1.5：视为突破有效，允许考虑做多；
  - 当日成交量 ≤ 该阈值：视为假突破，不交易。
- 突破触发：当前无持仓，且量能过滤通过，且当日收盘价 > Upper20（昨日收盘时计算）
  → 次日开盘买入。
- 收盘价跌破 Lower10 不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 通道出场：当日收盘价 < Lower10（昨日收盘时计算）→ 次日开盘平仓。
- 硬止损：止损价 = 入场价 − 2 × ATR(14)；ATR 取入场日收盘的 ATR(14)，
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 执行优先级：硬止损优先于通道出场。
- 本策略不设固定止盈；离场以通道出场与硬止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 2 × ATR(14)，
  克数 = 总资金 × 2% ÷ (2 × ATR(14))。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「量能过滤 + 突破触发」：不交易。
- 突破但量能不足：视为假突破，不交易。
- 已有持仓：只管理出场，不新开仓位；持仓期间再次突破也不加仓。
- 跌破 Lower10 时若已无持仓：不交易，不反向开空。

## 策略三：布林带挤压突破（BollingerSqueeze）

【信号周期】

- 数据：日 K 线（收盘价）。
- 计算时点：布林带（周期 20、偏离 2.0，参数可调）、
  带宽 = (上轨 − 下轨) ÷ 中轨、带宽分位数（近 200 日的 10% 分位）、
  ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 波动率过滤（带宽分位，近 200 日）：
  - 昨日带宽 < 近 200 日带宽的 10% 分位（昨日数值）：视为波动率挤压、市场蓄力，
    允许考虑做多；
  - 昨日带宽 ≥ 该分位：视为无挤压，不追突破，不交易。
- 突破触发：当前无持仓，且波动率过滤通过，且当日收盘价 > 当日布林上轨，
  且当日带宽 ≥ 昨日带宽 × 1.3（扩张 ≥ 30%）→ 次日开盘买入。
- 收盘价跌破布林下轨不构成空头入场条件，也不单独触发平仓。

【出场条件】

- 中轨出场：当日收盘价 < 当日布林中轨（SMA20）→ 次日开盘平仓。
- 硬止损：止损价 = 入场日布林中轨 − 1 × ATR(14)（ATR 取入场日值），
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 执行优先级：硬止损优先于中轨出场。
- 本策略不设固定止盈；离场以中轨出场与硬止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 信号日收盘价 − (布林中轨 − 1 × ATR(14))，
  克数 = 总资金 × 2% ÷ 每克止损距离。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「波动率过滤 + 突破触发 + 带宽扩张」：不交易。
- 突破上轨但昨日无挤压：不交易（无挤压的突破不追）。
- 已有持仓：只管理出场，不新开仓位。
- 调整布林带等参数后，全部历史信号需重新计算，不混用。

## 策略四：ATR 通道突破（Keltner 风格）（KeltnerBreakout）

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：EMA20、EMA60、ATR(14)、上通道 = EMA20 + 2 × ATR(14)、
  下通道 = EMA20 − 2 × ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤（均线方向，周期 20 / 60）：
  - EMA20 > EMA60：视为中期趋势向上，允许考虑做多；
  - EMA20 ≤ EMA60：视为中期趋势不明或向下，不交易。
- 突破触发：当前无持仓，且趋势过滤允许做多，
  且当日收盘价 > 昨日计算的上通道 → 次日开盘买入。
- 收盘价跌破下通道不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 持仓后启用移动止损，距离为 2 × ATR（周期 14，按当日值计算）。
- 多头：止损价 = max(前一止损价, 持仓期间最高收盘价 − 2 × ATR(14))，
  随行情上移，不随行情下移；收盘价触及或跌破止损价则次日开盘平仓。
- 通道出场：当日收盘价 < 当日下通道（EMA20 − 2 × ATR(14)）
  → 次日开盘平仓。
- 执行优先级：通道出场优先于移动止损；两者同日满足时按下通道出场处理。
- 本策略不设固定止盈，离场以移动止损与通道出场为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 2 × ATR(14)，
  克数 = 总资金 × 2% ÷ (2 × ATR(14))。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「趋势过滤 + 突破触发」：不交易。
- 突破上通道但 EMA20 ≤ EMA60：不交易（逆势突破不追）。
- 已有持仓：只管理出场，不新开仓位。
- 极端行情导致 ATR 快速放大时，通道与止损同步放宽，属正常行为，不人工干预。

## 策略五：RSI 均值回归（震荡市专用）（RsiMeanReversion）

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：RSI(14)、ADX(14)、ATR(14)、入场前 3 日最低价
  均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 市场状态过滤（ADX，周期 14）：
  - ADX(14) < 25：视为震荡市，本策略生效，允许考虑做多；
  - ADX(14) ≥ 25：视为强趋势市，本策略禁用（均值回归在趋势中易失效）。
- 超卖触发：当前无持仓，且处于震荡市，且当日 RSI(14) < 30
  → 次日开盘买入。
- 形态确认（如锤子线、看涨吞没）当前版本未实现，仅凭 RSI < 30 入场。
- RSI(14) > 70（超买）不构成空头入场条件，本策略不做空。

【出场条件】

- 硬止损：止损价 = 入场前 3 日最低价 − 1 × ATR(14)（ATR 取入场日值），
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 回归出场：RSI(14) 回升至 50 以上 → 次日开盘平仓。
- 时间止损：持仓满 10 个交易日（max\_hold\_bars=10）仍未触发上述任一出场条件
  → 次日开盘强制平仓（防止超卖后转入趋势性下跌）。
- 执行优先级：硬止损 > RSI 回归 > 时间止损。
- 本策略不设固定止盈价；离场以硬止损、RSI 回归、时间止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 信号日收盘价 − (入场前 3 日最低价 − 1 × ATR(14))，
  克数 = 总资金 × 2% ÷ 每克止损距离。
- 不加仓：持仓期间 RSI 再次跌破 30 也不增加克数。

【边界情况】

- ADX(14) ≥ 25（强趋势市）：策略整体禁用，不新开仓。
- 无持仓且未同时满足「震荡市过滤 + RSI 超卖触发」：不交易。
- 已有持仓期间 ADX 升至 25 以上：不立即平仓，按出场条件正常管理；
  若同时触发时间止损则加速离场。
- 已有持仓：只管理出场，不新开仓位。

## 附录：组合与风控建议

1. **多策略分散**：同时运行策略一A或一B（中频趋势）、策略二（低频突破）、策略五（震荡市专用）。趋势与均值回归天然互补——策略五的 ADX 过滤恰好在趋势策略最易失效的震荡市中工作。信号共振时加重仓位，信号分歧时轻仓或空仓。
2. **波动率目标仓位**：以 ATR(14) 滚动分位数动态调整总仓位——波动率处于高分位时整体减半，低分位时恢复，使风险敞口稳定。
3. **回测验证**：

   默认回测区间 2018-01-01 \~ 2026-09-01（含加息周期、降息周期、地缘冲突行情）

   熊市区间包括 2013-8-28 \~ 2015-7-31， 2020-8-7 \~ 2021-3-5， 2026-1-29 \~ 2026-7-1

   震荡市区间包括 2017-7-21 \~ 2018-1-17， 2018-5-25 \~ 2018-10-24，2021-7-8 \~ 2022-3-4

   回测策略应至少包含Buy-and-Hold，s1a, s1b
   
   回测指标包括：收益率、夏普比率、最大回撤、胜率、交易次数

   成本按单边手续费 0.02% + 滑点 0.02% 计。

   趋势策略在震荡期的连续小亏是固有成本，不应通过过度优化参数规避。
