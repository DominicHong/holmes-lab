## 统一约定（各策略共用）

【适用标的与数据】

- 数据：518880.SH 日 K 线（OHLC、成交量、成交额）；策略一C 使用同一标的的分钟线。
- 日线数据文件：data/518880.SH.csv（OHLC 单位为元/克，volume 单位为千克，amt 单位为亿元）。
- 分钟数据文件：data/518880.sh.minutes.csv（仅策略一C 使用，OHLC 单位为元/份，volume 单位为份）。
- 计算时点：除策略一C 在 14:45 快照计算外，其余策略的指标均在日 K 线收盘后计算与更新，不在盘中抢跑。

【多头约束】

- 只能做多，不能做空。传统 CTA 中的空头信号（死叉、跌破下轨、RSI 超买等）
  一律只触发「平掉多仓」，绝不反向开空。
- 空仓期为合法状态：信号不满足时保持空仓等待，不强制交易。

【执行时点】

- 信号在当日日 K 线收盘后确认；所有买入与卖出均于次日执行。
- 例外：策略一C 于 14:45 快照确认信号、当日 14:47 成交，卖出后最早 T+2 日再入场（见「策略一C」章节）。

【仓位模式】（common/constants.py 统一配置）

- 默认 percent\_equity：每次开仓金额 = 账户可用现金 × 100%，
  于次日开盘按实际开盘价（含滑点与手续费）折算克数，向下取整到 1 克；
  信号仍于当日收盘确认。
- 策略一B为该模式的系数化版本（仓位系数 ∈ {25%, 50%, 75%, 100%}），详见「策略一B」章节。

【跳空处理】

- 隔夜受国际金价与人民币汇率影响可能跳空；
  出场价位被跳空穿越时，按次日开盘价成交，实际盈亏可能与理论值偏离。

**【回测验证】**

- **默认回测区间** 2018-01-01 \~ 2026-09-01（含加息周期、降息周期、地缘冲突行情）
- **熊市区间**包括 2014-3-17 \~ 2015-8-10， 2020-8-7 \~ 2021-3-5， 2026-1-29 \~ 2026-7-1
- **震荡市区间**包括 2017-7-21 \~ 2018-1-17， 2018-5-25 \~ 2018-10-24，2021-7-8 \~ 2022-3-4
- **回测策略**应至少包含Buy-and-Hold，s1a,  s1c
- **区间窗口预热**应为“窗口前预热、窗口起点空仓”，确保在窗口起点已经预热完毕。
- **回测指标**包括：收益率、夏普比率、最大回撤、胜率、交易次数
- **成本**：成本按单边手续费 0.02% + 滑点 0.02% 计。
- **趋势策略**在震荡期的连续小亏是固有成本，不应通过过度优化参数规避。

## 策略一A：双均线趋势跟踪 + ATR 移动止损 + 趋势再入场（MaCrossTrailingStop）

【信号周期】

- 数据：日 K 线（收盘价）。
- 计算时点：SMA30、SMA90、ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤：今日 SMA30 > SMA90，且今日收盘价 > SMA90 → 视为趋势向上。
- 趋势再入场：当前无持仓且趋势向上 → 次日开盘买入，不必等待新的金叉；
  被止损打出后，只要趋势仍向上即重新入场。
- 死叉不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)，ATR 取入场日收盘的 ATR(14)，
  持仓期间固定，作为移动止损的下限。
- 移动止损：止损价 = max(初始止损, 持仓期最高收盘价 − 2.5 × ATR(入场日))，
  只上移不下移。收盘价触及或跌破止损价 → 次日开盘平仓。
- 趋势出场：死叉确认 → 次日开盘平仓。
- 执行优先级：移动止损优先于死叉。
- 本策略不设固定止盈，也不设加仓规则。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- 不加仓。

【边界情况】

- 趋势向上期间空仓即入场；SMA30 ≤ SMA90 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2×ATR。
- 参数：SMA 30 / 90、ATR 14、初始止损 2.5×ATR、移动止损 2.5×ATR。
- 参数调整记录：2026-09 由 SMA 20/60 + 2.0/2.5 调整为 SMA 30/90 + 2.5/2.5。
  2018-2026 全区间收益/Sharpe 改善（518880：163%→235%），震荡市无系统性伤害；
  但熊市防御不优于旧参数：2026 高位急跌窗口最大回撤 25.1%（旧参数同期 20.5%），
  2013-2015 长熊区间收益 -8.8%（旧参数 -2.1%）。

## 策略一B：双均线趋势跟踪 + 波动率目标仓位（VolTargetMaCross，代码 s1b）★ 首推

策略一A 的**仓位层改造版**：入场信号、移动止损、死叉出场与再入场规则与策略一A **完全一致**，
唯一变化是把「固定 100% 仓位」换成「波动率目标仓位」。
其余策略解决的是「什么时候进」，本策略解决「进多少」，与它们互补。

【设计思路】

- 固定满仓意味着波动越大时承担的实际风险越大，而波动放大往往正是趋势末端的特征。
- 波动率目标把风险敞口拉平：波动低时满仓、波动高时自动降档，使日均风险贡献大致恒定。
- 改造成本极低：不需要新信号、新数据源，只在下单前乘一个系数；
  它不改变信号的择时能力，只改变风险的分布形状。

【信号周期】

- 数据：日 K 线（收盘价）。
- 指标：SMA30、SMA90、ATR(14)（与策略一A 完全相同）；新增 RV60（60 日已实现波动率，年化）。
- RV60 = 过去 60 日（含当日）日收益率的样本标准差 × √252，在信号日收盘即可算出，无未来函数。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤：今日 SMA30 > SMA90，且今日收盘价 > SMA90 → 视为趋势向上。
- 趋势再入场：当前无持仓且趋势向上 → 次日开盘买入，不必等待新的金叉；
  被止损打出后，只要趋势仍向上即重新入场（与策略一A 一致，无冷却期）。
- 死叉不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)，ATR 取入场日收盘的 ATR(14)，持仓期间固定，作为移动止损下限。
- 移动止损：止损价 = max(初始止损, 持仓期最高收盘价 − 2.5 × ATR(入场日))，只上移不下移；
  收盘价触及或跌破止损价 → 次日开盘平仓。
- 趋势出场：死叉确认（SMA30 ≤ SMA90）→ 次日开盘平仓。
- 执行优先级：移动止损优先于死叉。不设固定止盈；加仓只由波动率档位上移触发，趋势信号不重复加仓。

【仓位规则】——本策略唯一的新增部分

- 目标仓位 = 信号仓位（0 或 1）× 波动率系数 f。
- 波动率系数：`f = min(1.0, 目标年化波动 15% ÷ RV60)`。
- **档位化（抑制换手）**：`f = max(0.25, round(f × 4) ÷ 4)`，即只取
  **25% / 50% / 75% / 100%** 四档；网格避免每日微调仓位导致的无谓交易成本，是本模块能否实用的关键。
- 建仓：次日开盘按「账户可用现金 × f」折算克数（含滑点与手续费），向下取整到 1 克。
- 持仓期**按档位加减仓**：档位变化（上移或下移）时，次日开盘把持仓调整到
  「账户权益 × 新档位」对应的目标克数——上移加仓（受可用现金约束）、下移部分减仓。
- 档位变化不重置止损状态机（初始止损、移动止损仍按建仓日 ATR 计），
  也不计入胜率统计的完整回合（backtrader 部分减仓不产生独立回合）。
- 档位对照：

| RV60（年化） | 理论 f = 15% ÷ RV60 | 档位化后 f | 说明                 |
| -------- | ---------------- | ------ | ------------------ |
| 8%       | 1.88             | 1.00   | 低波动，封顶满仓           |
| 12%      | 1.25             | 1.00   | 低波动，封顶满仓           |
| 20%      | 0.75             | 0.75   | 中波动，降至 3/4 仓       |
| 30%      | 0.50             | 0.50   | 高波动，降至半仓           |
| 60%      | 0.25             | 0.25   | 极端波动（2020-08、2026-01） |
| > 60%    | < 0.25           | 0.25   | 档位下限，不再继续降（防踏空）    |

- **档位下限 25% 而非 0**：黄金长期上行，极端波动期完全清仓会错过 V 型反转；
  下限设为 1/4 仓是「降低风险」与「保留敞口」的折中。

【参数表】

| 类别 | 参数        | 默认值                     | 敏感性      |
| -- | --------- | ----------------------- | -------- |
| 趋势 | SMA 快 / 慢 | 30 / 90                 | 与策略一A 同  |
| 波幅 | ATR 周期    | 14                      | 同        |
| 止损 | 初始止损      | 2.5 × ATR               | 同        |
| 止损 | 移动止损      | 2.5 × ATR               | 同        |
| 仓位 | 目标年化波动    | 15%                     | 低        |
| 仓位 | 实现波动窗口    | 60 日                    | 低        |
| 仓位 | 档位网格      | 25%（4 档）                | 中（核心）    |
| 仓位 | 档位下限      | 25%                     | 低        |
| 仓位 | 仓位模式      | percent\_equity（系数乘数）   | —        |

【边界情况】

- 趋势向上期间空仓即入场；SMA30 ≤ SMA90 后空仓等待。
- 移动止损仅在持仓期内上移；平仓后重置，下次入场按新入场日 ATR 重新计算。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过 2.5 × ATR。
- **低波动期系数恒为 1**：当 RV60 < 15% 时 f 被封顶到 100%，此时策略一B与策略一A 的持仓与成交逐笔一致。
- RV60 在窗口未满 60 日时为空值，此时按 f = 1.0（满仓）处理，不降档。
- 持仓期档位双向调仓：同一档位反复穿越（RV60 在 15% / 24% 等边界附近震荡）会产生多次调仓成本，
  25% 的档位网格与低频边界穿越使实际调仓保持在每年个位数。
- 档位调仓（加仓 / 减仓）按单边 0.02% 费 + 0.02% 滑点计成本，但不算作完整回合。

【与策略一A的差异对照】

| 模块                         | 策略一A（s1a） | 策略一B（s1b）                  |
| -------------------------- | --------- | ------------------------- |
| 择时（趋势过滤 / 移动止损 / 死叉出场 / 再入场） | 相同        | 相同                        |
| 建仓仓位                       | 固定 100%   | 100% × f（25% / 50% / 75% / 100%） |
| 持仓期仓位                      | 不变        | 档位变化即调仓：上移加仓、下移减仓         |
| 数据需求                       | 收盘价       | 收盘价 + RV60                 |

> 详细回测对比（全区间 + 3 熊市 + 3 震荡）见 `strategies/au9999_cta/results/window_comparison_s1a_s1b/report.md`；复现：`python -m strategies.au9999_cta.compare_windows --strategies buy_and_hold s1a_ma_cross_trailing s1b_vol_target_ma_cross --results-dir strategies/au9999_cta/results/window_comparison_s1a_s1b`。

## 策略一C：双均线趋势跟踪 + ATR 移动止损 + 盘中提前成交 + T+2 再入场（IntradayMaCrossTrailingStop）

策略一A 的盘中执行版：趋势过滤、移动止损与死叉出场规则与策略一A 完全一致，
仅将「15:00 收盘确认、次日开盘执行」改为「14:45 快照确认、当日 14:47 执行」，
并在卖出后加入 T+2 再入场约束。设计目标：趋势反转或触及止损时抢先离场，
规避隔夜与周末跳空造成的超额损失。

【信号周期】

- 数据：518880.SH 分钟线（data/518880.sh.minutes.csv），不使用日 K 线文件。
- 指标口径：SMA30、SMA90、ATR(14) 以每日 14:45 快照计算——
  「当日收盘价」取 14:45 分钟收盘价，ATR 的 high/low 取 9:30 \~ 14:45 区间；
  指标序列仍为日频（每交易日一个快照），但不使用 15:00 日 K 线收盘价。
- 信号判断：仅在该日 14:45 快照后进行；满足条件时于当日 14:47 分钟收盘价成交。
- 指标周期在数据装载阶段（common/data\_loader.load\_minute\_snapshots）固定为
  SMA 30/90、ATR 14，与策略一A 参数需同步修改。

【入场条件】

- 趋势过滤：14:45 快照 SMA30 > SMA90，且 14:45 收盘价 > SMA90 → 视为趋势向上。
- 首次入场：当前无持仓、趋势向上且不在再入场冷却期 → 当日 14:47 买入，不必等待新的金叉。
- 趋势再入场：卖出成交日记为 T 日，最早在 T+2 日 14:45 重新判断，趋势仍向上则 14:47 重新入场；
  T+1 日即使趋势向上也不反手，用于过滤连环止损；延迟由参数 reentry\_delay 控制（默认 2，设为 1 即次日）。
- 死叉不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)，ATR 取入场日 14:45 快照值，持仓期间固定。
- 移动止损：止损价 = max(初始止损, 持仓期 14:45 最高收盘价 − 2.5 × ATR(入场日))，只上移不下移。
- 出场触发：14:45 快照收盘价触及或跌破止损价，或死叉确认 → 当日 14:47 卖出。
- 执行优先级：移动止损优先于死叉；不设固定止盈，不加仓。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）；按 14:47 实际成交价（含滑点与手续费）
  折算克数，向下取整到 1 克。

【边界情况】

- 14:45 快照不含尾盘 15 分钟与收盘集合竞价，极端行情下尾盘走势可能改变原日线信号。
- T 日 14:47 离场比策略一A 的次日开盘早约 17.5 小时，但 T+1 开盘跳空仍无法规避。
- 冷却按交易日计数：T 日卖出，T+1 日不入场，T+2 日 14:45 恢复判断。
- 分钟数据自 2013-07-29 起，更早的回测区间不可用。

【与策略一A的差异对照】

| 模块     | 策略一A（日线）                    | 策略一C（盘中）                   |
| ------ | --------------------------- | -------------------------- |
| 数据     | 518880.SH 日 K 线             | 518880.SH 分钟线（14:45 快照）    |
| 信号时点   | 15:00 收盘                    | 14:45 快照                   |
| 成交时点   | 次日 09:30 开盘                 | 当日 14:47                   |
| 止损后再入场 | 趋势向上即次日开盘反手                 | 最早 T+2 日 14:45 判断、14:47 成交 |
| 其它     | 相同（趋势过滤 / 移动止损 / 死叉出场 / 仓位） | 相同                         |

【回测（518880.SH，窗口前预热、窗口起点空仓，成本单边 0.02% 费 + 0.02% 滑点）】

| 策略     | 总收益    | 最大回撤  | Sharpe | 交易次数 | 胜率    |
| ------ | ------ | ----- | ------ | ---- | ----- |
| s1a 日线 | 227.4% | 25.1% | 1.10   | 56   | 55.4% |
| s1c 盘中 | 222.3% | 18.4% | 1.19   | 53   | 52.8% |

- 差异集中在隔夜跳空：2026 高位急跌区间 s1c -10.1% / 回撤 13.5%，
  策略一A -12.4% / 回撤 22.1%（同为 2026-01-30 触及止损：日线口径只能 2026-02-02
  在周末跳空后开盘卖出，盘中口径当日 14:47 已离场）。
- 代价：常态年份因 T+2 延迟再入场略跑输（2018-2025 段 s1c 179.3% vs s1a 203.4%）；
  2014-03-17 \~ 2015-08-10 长熊区间 s1c -15.8% vs s1a -12.4%。
- 定性：该改动是降低尾部跳空风险的保险，换来回撤与 Sharpe 改善，而非系统性收益优势；
  是否采用取决于对隔夜跳空的容忍度。

## 策略二：唐奇安通道突破（20 日入场 / 10 日出场）（DonchianBreakout）

【信号周期】

- 数据：日 K 线（收盘价、成交量）。
- 计算时点：Upper20（前 20 日最高价）、Lower10（前 10 日最低价）、
  前 20 日平均成交量、ATR(14) 均在日 K 线收盘后计算与更新；
  通道与均量窗口均不含当日，即当日只与「昨日及之前」的窗口比较。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 量能过滤（前 20 日均量 × 1.5）：
  - 当日成交量 > 前 20 日（不含当日）平均成交量 × 1.5：视为突破有效，允许考虑做多；
  - 当日成交量 ≤ 该阈值：视为假突破，不交易。
- 突破触发：当前无持仓，且量能过滤通过，且当日收盘价 > Upper20（昨日收盘时计算）
  → 次日开盘买入。
- 收盘价跌破 Lower10 不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 通道出场：当日收盘价 < Lower10（昨日收盘时计算）→ 次日开盘平仓。
- 硬止损：止损价 = 入场价 − 2 × ATR(14)；ATR 取入场日收盘的 ATR(14)，
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 执行优先级：硬止损优先于通道出场。
- 本策略不设固定止盈；离场以通道出场与硬止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 2 × ATR(14)，
  克数 = 总资金 × 2% ÷ (2 × ATR(14))。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「量能过滤 + 突破触发」：不交易。
- 突破但量能不足：视为假突破，不交易。
- 已有持仓：只管理出场，不新开仓位；持仓期间再次突破也不加仓。
- 跌破 Lower10 时若已无持仓：不交易，不反向开空。

## 策略三：布林带挤压突破（BollingerSqueeze）

【信号周期】

- 数据：日 K 线（收盘价）。
- 计算时点：布林带（周期 20、偏离 2.0，参数可调）、
  带宽 = (上轨 − 下轨) ÷ 中轨、带宽分位数（近 200 日的 10% 分位）、
  ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 波动率过滤（带宽分位，近 200 日）：
  - 昨日带宽 < 近 200 日带宽的 10% 分位（昨日数值）：视为波动率挤压、市场蓄力，
    允许考虑做多；
  - 昨日带宽 ≥ 该分位：视为无挤压，不追突破，不交易。
- 突破触发：当前无持仓，且波动率过滤通过，且当日收盘价 > 当日布林上轨，
  且当日带宽 ≥ 昨日带宽 × 1.3（扩张 ≥ 30%）→ 次日开盘买入。
- 收盘价跌破布林下轨不构成空头入场条件，也不单独触发平仓。

【出场条件】

- 中轨出场：当日收盘价 < 当日布林中轨（SMA20）→ 次日开盘平仓。
- 硬止损：止损价 = 入场日布林中轨 − 1 × ATR(14)（ATR 取入场日值），
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 执行优先级：硬止损优先于中轨出场。
- 本策略不设固定止盈；离场以中轨出场与硬止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 信号日收盘价 − (布林中轨 − 1 × ATR(14))，
  克数 = 总资金 × 2% ÷ 每克止损距离。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「波动率过滤 + 突破触发 + 带宽扩张」：不交易。
- 突破上轨但昨日无挤压：不交易（无挤压的突破不追）。
- 已有持仓：只管理出场，不新开仓位。
- 调整布林带等参数后，全部历史信号需重新计算，不混用。

## 策略四：ATR 通道突破（Keltner 风格）（KeltnerBreakout）

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：EMA20、EMA60、ATR(14)、上通道 = EMA20 + 2 × ATR(14)、
  下通道 = EMA20 − 2 × ATR(14) 均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 趋势过滤（均线方向，周期 20 / 60）：
  - EMA20 > EMA60：视为中期趋势向上，允许考虑做多；
  - EMA20 ≤ EMA60：视为中期趋势不明或向下，不交易。
- 突破触发：当前无持仓，且趋势过滤允许做多，
  且当日收盘价 > 昨日计算的上通道 → 次日开盘买入。
- 收盘价跌破下通道不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 持仓后启用移动止损，距离为 2 × ATR（周期 14，按当日值计算）。
- 多头：止损价 = max(前一止损价, 持仓期间最高收盘价 − 2 × ATR(14))，
  随行情上移，不随行情下移；收盘价触及或跌破止损价则次日开盘平仓。
- 通道出场：当日收盘价 < 当日下通道（EMA20 − 2 × ATR(14)）
  → 次日开盘平仓。
- 执行优先级：通道出场优先于移动止损；两者同日满足时按下通道出场处理。
- 本策略不设固定止盈，离场以移动止损与通道出场为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 2 × ATR(14)，
  克数 = 总资金 × 2% ÷ (2 × ATR(14))。
- 不加仓。

【边界情况】

- 无持仓且未同时满足「趋势过滤 + 突破触发」：不交易。
- 突破上通道但 EMA20 ≤ EMA60：不交易（逆势突破不追）。
- 已有持仓：只管理出场，不新开仓位。
- 极端行情导致 ATR 快速放大时，通道与止损同步放宽，属正常行为，不人工干预。

## 策略五：RSI 均值回归（震荡市专用）（RsiMeanReversion）

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：RSI(14)、ADX(14)、ATR(14)、入场前 3 日最低价
  均在日 K 线收盘后计算与更新。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【入场条件】

- 市场状态过滤（ADX，周期 14）：
  - ADX(14) < 25：视为震荡市，本策略生效，允许考虑做多；
  - ADX(14) ≥ 25：视为强趋势市，本策略禁用（均值回归在趋势中易失效）。
- 超卖触发：当前无持仓，且处于震荡市，且当日 RSI(14) < 30
  → 次日开盘买入。
- 形态确认（如锤子线、看涨吞没）当前版本未实现，仅凭 RSI < 30 入场。
- RSI(14) > 70（超买）不构成空头入场条件，本策略不做空。

【出场条件】

- 硬止损：止损价 = 入场前 3 日最低价 − 1 × ATR(14)（ATR 取入场日值），
  持仓期间固定；收盘价触及或跌破止损价 → 次日开盘平仓。
- 回归出场：RSI(14) 回升至 50 以上 → 次日开盘平仓。
- 时间止损：持仓满 10 个交易日（max\_hold\_bars=10）仍未触发上述任一出场条件
  → 次日开盘强制平仓（防止超卖后转入趋势性下跌）。
- 执行优先级：硬止损 > RSI 回归 > 时间止损。
- 本策略不设固定止盈价；离场以硬止损、RSI 回归、时间止损为准。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）。
- risk\_budget 模式：每克止损距离 = 信号日收盘价 − (入场前 3 日最低价 − 1 × ATR(14))，
  克数 = 总资金 × 2% ÷ 每克止损距离。
- 不加仓：持仓期间 RSI 再次跌破 30 也不增加克数。

【边界情况】

- ADX(14) ≥ 25（强趋势市）：策略整体禁用，不新开仓。
- 无持仓且未同时满足「震荡市过滤 + RSI 超卖触发」：不交易。
- 已有持仓期间 ADX 升至 25 以上：不立即平仓，按出场条件正常管理；
  若同时触发时间止损则加速离场。
- 已有持仓：只管理出场，不新开仓位。

## 策略七：唐奇安通道突破 + MACD 动量过滤 + ATR 自适应止损（MacdTurtle，代码 s7，30/15 版）

**趋势通道突破 + 动量过滤**的组合：以唐奇安通道突破定位新趋势的起点，
用 MACD 柱过滤掉缺乏动量的假突破，用 ATR 自适应止损管理持仓，
并在 MACD 转弱时**收紧（而非直接平仓）**止损；是策略二的通道增强版。

【设计思路】

- 通道突破类策略（策略二）用「价格创出 N 日新高」确认趋势，在趋势启动阶段入场最快；
  缺点是震荡市假突破多、来回止损。
- MACD 提供两个额外信息：**入场端**筛掉「创新高但没有动量」的突破；
  **出场端**识别动量衰竭，但它天然滞后、直接平仓容易在洗盘中被甩下车。
- 因此本策略把 MACD 放在**出场端收紧止损**而非直接平仓：柱翻负时止损系数由 2.5×ATR
  收紧到 1.5×ATR——既保护利润，又保留 MACD 重新转强后继续持有的可能。
- 通道参数从海龟原版的 20/10 放大到 **30/15**，以过滤震荡市假突破。

【信号周期】

- 数据：日 K 线（收盘价、最高价、最低价）。
- 计算时点：MACD(12, 26, 9)、唐奇安上轨 Up30（前 30 日最高价）、
  唐奇安下轨 Dn15（前 15 日最低价）、ATR(14) 均在日 K 线收盘后计算与更新；
  **通道窗口均不含当日**，即当日只与「昨日及之前」的窗口比较。
- 信号判断：仅在该日 K 线收盘后进行；满足入场条件时，于次日开盘执行买入。

【指标体系】

- 唐奇安通道（海龟原版口径）：
  - `Up30(i) = max(high[i-30 .. i-1])`，即前 30 日最高价，不含当日；
  - `Dn15(i) = min(low[i-15 .. i-1])`，即前 15 日最低价，不含当日。
- MACD：`DIF = EMA(12) − EMA(26)`，`DEA = EMA(DIF, 9)`，`HIST = (DIF − DEA) × 2`。
- ATR(14)：Wilder 平滑的真实波幅。
- MACD「转弱」判据：`HIST < 0` **或** `DIF < DEA`（同一条件的两种等价表述）。

【入场条件】

- 突破触发：当前无持仓，且**当日收盘价 > Up30** → 突破候选。
- 动量过滤：且**当日 HIST > 0**（MACD 柱为正）→ 视为动量确认，允许做多。
- 执行：次日开盘买入，仓位 100%。
- 两条件需**同时满足**；仅突破而 MACD 柱为负 → 视为动量不足的假突破，不交易。
- 收盘价跌破 Dn15 不构成空头入场条件，仅用于持仓出场。

【出场条件】

- 初始止损：入场价 − 2.5 × ATR(14)；ATR 取入场日收盘的 ATR(14)，持仓期间固定，作为止损绝对下限。
- 动态止损（MACD 自适应，**每日重算**）：

| MACD 状态                  | 止损系数    | 计算基准     |
| ------------------------ | ------- | -------- |
| 正常（HIST > 0 且 DIF ≥ DEA） | 2.5×ATR | 持仓期最高收盘价 |
| 转弱（HIST < 0 或 DIF < DEA） | 1.5×ATR | 持仓期最高收盘价 |

止损价 = `max(初始止损, 持仓期最高收盘价 − 系数 × ATR(入场日))`。

- 通道出场：当日收盘价 < Dn15（前 15 日最低价）→ 次日开盘平仓。
- 执行优先级：**止损优先于通道出场**（任一触发即次日开盘平仓）。不设固定止盈，不加仓。

【仓位规则】

- 仓位模式见统一约定（默认 percent\_equity 100%）；目标仓位恒为 0 或 1。
- 不加仓：持仓期间即使再次突破也不增加克数。
- risk\_budget 模式：每克止损距离 = 2.5 × ATR(14)，克数 = 总资金 × 2% ÷ 每克止损距离。

【参数表】

| 类别 | 参数              | 默认值         | 说明                        |
| -- | --------------- | ----------- | ------------------------- |
| 通道 | 入场周期            | 30 日        | 海龟原版为 20，本策略放大至 30（见敏感性）  |
| 通道 | 出场周期            | 15 日        | 海龟原版为 10，本策略放大至 15        |
| 动量 | MACD 快 / 慢 / 信号 | 12 / 26 / 9 | 标准参数，未做优化                 |
| 波幅 | ATR 周期          | 14          | —                         |
| 止损 | 基础（正常）止损        | 2.5 × ATR   | 亦用于初始止损                   |
| 止损 | 收紧（MACD 转弱）止损   | 1.5 × ATR   | 触发条件：HIST < 0 或 DIF < DEA |
| 仓位 | 目标仓位            | 0 / 100%    | —                         |

【边界情况】

- 无持仓且未同时满足「突破 + 动量确认」：不交易；突破 Up30 但 HIST ≤ 0：不追。
- 已有持仓：只管理出场，不新开仓位；持仓期间再次突破也不加仓。
- 跌破 Dn15 时若已无持仓：不交易，不反向开空。
- **止损每日重算，不是「只上移」的严格棘轮**：最高收盘价只增不减，
  但止损系数随 MACD 状态在 2.5 / 1.5 之间切换，因此当 MACD 由弱转强时，
  止损价会随系数放宽而下移（回到 2.5×ATR 的位置）。这一设计是为了给「动量恢复」留出空间，
  代价是放弃一部分已锁定的利润。
- 隔夜跳空越过止损价：按次日开盘价平仓，实际亏损可能超过止损距离。

【与策略二的差异对照】

| 模块   | 策略二（s2）                        | 策略七（s7）                          |
| ---- | ------------------------------- | --------------------------------- |
| 入场   | 突破 Up20 + 量能 > 20 日均量 × 1.5      | 突破 Up30 + MACD 柱 > 0               |
| 出场   | 跌破 Dn10，或 入场价 − 2×ATR 硬止损       | 跌破 Dn15，或 ATR 自适应止损 2.5 / 1.5×ATR |
| 止损口径 | 固定（入场日 ATR）                     | 每日重算，随 MACD 松紧，下有初始止损托底           |
| 数据需求 | 收盘价 + 成交量                       | 收盘价 + 最高价 + 最低价                   |

> 详细回测对比（全区间 + 3 熊市 + 3 震荡）见 `strategies/au9999_cta/results/window_comparison_s2_s7/report.md`；复现：`python -m strategies.au9999_cta.compare_windows --strategies buy_and_hold s2_donchian_breakout s7_macd_turtle --results-dir strategies/au9999_cta/results/window_comparison_s2_s7`。

## 附录：组合与风控建议

1. **多策略分散**：同时运行策略一A / 一B / 一C（中频趋势，取其一）、策略二 / 策略七（低频突破，取其一）、策略五（震荡市专用）。趋势与均值回归天然互补——策略五的 ADX 过滤恰好在趋势策略最易失效的震荡市中工作。策略七与策略一A 的日收益相关性最低（约 0.64），适合作为独立的趋势腿。信号共振时加重仓位，信号分歧时轻仓或空仓。
2. **波动率目标仓位**：直接采用策略一B的 RV60 目标仓位机制（`f = min(1, 15% ÷ RV60)` 档位化到 25% 一档），或对多策略组合按 ATR(14) 滚动分位数整体加减仓——波动率处于高分位时整体减半，低分位时恢复，使风险敞口稳定。
