# 国债税前收益率四种算法对比报告

> 样本：54 只合成国债（2 种付息频率 × 3 个期限档 × 3 个 t 档 × 3 个票息档）
> 统一 YTM：3.00%；税率：25%；计息规则：ACT_ACT_ICMA
> 基准日：2026-11-12 所在计息期；t ≈ 0.1 / 0.5 / 0.9
> 数据与图片由 `tools/ytm_tax_method_compare.py` 生成

---

## 摘要

本报告对比四种"国债税前等效收益率"算法：

1. **IRR**：构造恒定票息 K 的虚拟应税债，使其税后 IRR 等于国债 YTM；
2. **Varied Coupon**：构造首期票息不同、后续票息恒定的虚拟债，使其税后现金流与国债完全一致；
3. **Reference**：超简便公式 \(y=r+\frac{cT}{1-T}\)；
4. **Ref-4**：一次简式 \(y=r+\frac{1/n+r}{1/n+c}\cdot\frac{cT}{1-T}\)（按期计算后年化）。

主要结论：

- **IRR 与 Varied 都是数值精确解，但定义不同**。两者在 t=1 时严格相等；t=0.9 时平均只差 0.036bp；t=0.1 时平均差 4.95bp，最坏 17.27bp（2 年、5% 票息、年付）。
- **两个闭式公式本质上是对 Varied 的近似**，因此评估其精度应以 Varied 为基准：
  - Reference 相对 Varied：平均 4.45bp，最大 16.47bp；
  - Ref-4 相对 Varied：平均 2.31bp，最大 7.22bp。
- **Ref-4 是更稳的闭式解**：整体误差约为 Reference 的一半，高票息（5%）场景优势最明显（4.04bp vs 10.50bp）。
- **Reference 只在平价附近够用**：3% 票息（平价）时相对 Varied 平均 1.13bp；5% 票息（溢价）时平均 10.50bp、最大 16.47bp。
- **t 是重要变量**：t≈0.9 时四种算法明显收敛；t≈0.1 时差异最大。中段交割（t≈0.5）也不能简单套用平价公式。
- **最坏的角落**是"年付 + 2 年短债 + t≈0.1 + 5% 高票息"：IRR−Varied −17.27bp，IRR−Reference −24.15bp，IRR−Ref-4 −18.09bp。

## 1. 问题定义与符号

免税国债的到期收益率为 \(r\)，票面利率为 \(c\)，每年付息 \(f\) 次，剩余付息次数为 \(n\)。投资者希望知道：一只**不免税**的应税债，需要达到多少税前到期收益率 \(y\)，才能与这只国债等价？

| 符号 | 含义 |
|---|---|
| \(f\) | 每年付息次数（本报告取 1 或 2） |
| \(c\) | 年化票面利率 |
| \(r\) | 国债年化到期收益率（本报告固定 3%） |
| \(y\) | 待求的应税债税前年化到期收益率 |
| \(T\) | 所得税率（25%） |
| \(n\) | 剩余付息次数 |
| \(t\) | \(\dfrac{\text{下一付息日}-\text{交割日}}{\text{下一付息日}-\text{上一付息日}}\)，\(0\le t\le 1\) |
| \(P_0\) | 国债当前全价 |

记每期票息 \(c_p=c/f\)、每期收益率 \(r_p=r/f\)。交割日之前已经产生的应计利息归属卖方，买方买入后只对持有期内的利息缴税；因此首期现金流存在"税基残差"，这正是 \(t\) 进入公式的原因。

## 2. 四种算法

### 2.1 IRR 版：恒定票息虚拟债

构造一只**票息恒定**的虚拟应税债，票息为 \(K\)。要求它在与国债相同的全价 \(P_0\) 下，**税后 IRR 恰好等于国债的 \(r\)**。

税后现金流为：首期 \(K(1-tT)\)，之后每期 \(K(1-T)\)，到期另有本金 1。于是：

$$
P_0=\frac{K(1-tT)}{(1+r/f)^{t}}+\sum_{k=1}^{n-1}\frac{K(1-T)}{(1+r/f)^{t+k}}+\frac{1}{(1+r/f)^{t+n-1}}
\tag{1}
$$

记

$$
v=\frac{1}{1+r/f},\qquad A=\sum_{k=0}^{n-1}v^{\,t+k}
\tag{2}
$$

可解出闭式

$$
\boxed{\;K=\frac{c_p A}{(1-T)A+T(1-t)v^{t}}\;}
\tag{3}
$$

再把同一只虚拟债换成**税前**现金流贴现，解出 \(y\)：

$$
P_0=\sum_{k=0}^{n-1}\frac{K}{(1+y/f)^{t+k}}+\frac{1}{(1+y/f)^{t+n-1}}
\tag{4}
$$

实现见 [irr_yield](file:///f:/MyWork/GitHubProjects/holmes-lab/tools/ytm_before_tax_ifind.py#L303)。

### 2.2 Varied Coupon 版：时变票息虚拟债

构造一只虚拟债，使它的**税后现金流与国债完全相同**。首期票息需要放大为 \(c_p/(1-tT)\)，之后各期为 \(c_p/(1-T)\)：

$$
P_0=\frac{c_p/(1-tT)}{(1+y/f)^{t}}+\sum_{k=1}^{n-1}\frac{c_p/(1-T)}{(1+y/f)^{t+k}}+\frac{1}{(1+y/f)^{t+n-1}}
\tag{5}
$$

这是《国债还原税前收益率速算公式》的原始构造。它的首期与后续票息不同，现实中不存在这样的债券，但税后现金流与国债逐期完全一致。

实现见 [varied_coupon_yield](file:///f:/MyWork/GitHubProjects/holmes-lab/tools/ytm_before_tax_ifind.py#L336)。

### 2.3 Reference：超简便公式

$$
\boxed{\;y=r+\frac{cT}{1-T}\;}
\tag{6}
$$

它假设所有票息都按同一税率放大，忽略了 \(t\)、\(n\) 以及折溢价带来的资本利得/损失。实现见 [reference_yield](file:///f:/MyWork/GitHubProjects/holmes-lab/tools/ytm_before_tax_ifind.py#L362)。

### 2.4 Ref-4：一次简式

约定 \(y_p=y/f,\ r_p=r/f,\ c_p=c/f\)：

$$
y_p=r_p+\frac{1/n+r_p}{1/n+c_p}\cdot\frac{c_pT}{1-T},\qquad y=f\,y_p
\tag{7}
$$

它比 Reference 多考虑了剩余付息次数 \(n\) 和票息水平对折溢价的影响。实现见 [reference_yield_formula4](file:///f:/MyWork/GitHubProjects/holmes-lab/tools/ytm_before_tax_ifind.py#L367)。

### 2.5 四者的关系

- **IRR 与 Varied 都是数值精确解**，但等价的定义不同：
  - IRR：虚拟债是"真实存在"的恒定票息债，税后 **IRR** 与国债打平；
  - Varied：虚拟债的税后**现金流**与国债逐期相同，但票息时变、现实中不存在。
- 当 \(t=1\)（刚付息完毕）时，两者严格相等：此时 \(K=c_p/(1-T)\)，IRR 版与 Varied 版退化为同一个方程。
- 当 \(t<1\) 时，两者分歧随 \(t\) 远离 1 而增大；本样本中最大 17.27bp。
- **Reference 与 Ref-4 都是对 Varied 的近似**（都来自时变票息的现金流对齐框架），因此评估它们的"内在精度"应以 Varied 为基准；以 IRR 为基准时，数值中还包含 IRR 与 Varied 的定义差。

## 3. 样本设计

### 3.1 维度

| 维度 | 取值 | 说明 |
|---|---|---|
| 付息频率 | 年付、半年付 | \(f=1,2\) |
| 期限档 | 短期、中期、长期 | 原始发行期限 2 / 5 / 10 年 |
| t 档 | 0.1 / 0.5 / 0.9 | 在基准日所在计息期内移动交割日 |
| 票息 | 1% / 3% / 5% | 相对 3% 的 YTM，分别为折价 / 平价 / 溢价 |

共 \(2\times3\times3\times3=54\) 个样本。

### 3.2 日期构造

| 频率 | 期限档 | 起息日 | 到期日 | 基准计息期 |
|---|---|---|---|---|
| 年付 | 短期 | 2026-05-15 | 2028-05-15 | 2026-05-15 ~ 2027-05-15 |
| 年付 | 中期 | 2026-05-15 | 2031-05-15 | 同上 |
| 年付 | 长期 | 2026-05-15 | 2036-05-15 | 同上 |
| 半年付 | 短期 | 2026-02-15 | 2028-02-15 | 2026-08-15 ~ 2027-02-15 |
| 半年付 | 中期 | 2026-02-15 | 2031-02-15 | 同上 |
| 半年付 | 长期 | 2026-02-15 | 2036-02-15 | 同上 |

- 基准交割日 2026-11-12 位于上表"基准计息期"内。
- 对每个 t 档，把交割日在该计息期内移动到剩余比例为 t 的日期；实际 t 由 `bond.alpha` 给出，年付约 0.099 / 0.499 / 0.899，半年付约 0.098 / 0.500 / 0.902。
- 因此"剩余年"会随 t 在一个付息期内变化（例如 2 年半年付从 1.05 年到 1.45 年），明细表中已列出。期限档与剩余付息次数 \(n\) 不受影响。
- 所有样本 \(n\ge2\)（年付 2/5/10，半年付 3/9/19），未触发 \(n=1\) 时 CFETS 最后付息周期的单利分支。

### 3.3 计算口径

- 国债全价 \(P_0\) 由输入 YTM 3% 按 FinancePy 的 CFETS 分支反算；\(n\ge2\) 时该分支就是式 (4)/(5) 的逐期复利形式。
- IRR 与 Varied 用数值求根；Reference 与 Ref-4 为闭式公式。
- 所有差异以 **bp** 为单位（1bp = 0.01%）。

## 5. 分维度结果

### 5.1 按 t 分档

以 IRR 为基准：

| t 档 | IRR−Varied 平均/最大 | IRR−Reference 平均/最大 | IRR−Ref-4 平均/最大 |
|---|---:|---:|---:|
| 0.1 | 4.947 / 17.272 | 8.419 / 24.150 | 5.521 / 18.089 |
| 0.5 | 1.373 / 4.373 | 6.382 / 17.346 | 3.652 / 10.288 |
| 0.9 | 0.036 / 0.100 | 4.244 / 16.051 | 1.946 / 6.691 |

以 Varied 为基准：

| t 档 | Reference 平均/最大 | Ref-4 平均/最大 |
|---|---:|---:|
| 0.1 | 3.954 / 15.045 | 2.208 / 7.217 |
| 0.5 | 5.169 / 16.474 | 2.810 / 6.472 |
| 0.9 | 4.237 / 16.126 | 1.912 / 6.651 |

要点：

- IRR−Varied 随 t 减小而显著放大：t=0.9 时几乎为 0，t=0.1 时平均接近 5bp。这与"t→1 时两种构造重合"的理论一致。
- Reference 与 Ref-4 对 t 的敏感度较低（它们要么完全忽略 t，要么只通过 n 间接处理），因此误差主要由票息/折溢价驱动。
- Ref-4 在 t=0.9 时最准（1.91bp），t=0.5 时最差（2.81bp），但整体都明显优于 Reference。

### 5.2 按频率

| 频率 | IRR−Varied 平均/最大 | IRR−Reference 平均/最大 | IRR−Ref-4 平均/最大 |
|---|---:|---:|---:|
| 年付 | 2.515 / 17.272 | 7.157 / 24.150 | 4.174 / 18.089 |
| 半年付 | 1.723 / 12.855 | 5.540 / 17.191 | 3.239 / 12.540 |

年付样本的误差普遍大于半年付：年付的付息次数少、单期现金流大，首期税基残差占整只债券现金流的比例更高。

### 5.3 按期限

| 期限档 | IRR−Varied 平均/最大 | IRR−Reference 平均/最大 | IRR−Ref-4 平均/最大 |
|---|---:|---:|---:|
| 短期（2Y） | 3.930 / 17.272 | 7.145 / 24.150 | 5.665 / 18.089 |
| 中期（5Y） | 1.641 / 7.522 | 5.021 / 16.312 | 2.261 / 5.581 |
| 长期（10Y） | 0.785 / 3.508 | 6.879 / 18.552 | 3.194 / 6.691 |

短债对 t 最敏感：首期在全部现金流中的占比最高，t 的处理方式直接决定结果。长债的 IRR−Varied 很小，但 Reference 仍因忽略折溢价而保持约 6.9bp 的平均误差。

### 5.4 按票息

| 票息 | IRR−Varied 平均/最大 | IRR−Reference 平均/最大 | IRR−Ref-4 平均/最大 |
|---:|---:|---:|---:|
| 1%（折价） | 0.797 / 3.743 | 1.874 / 3.745 | 2.559 / 5.053 |
| 3%（平价） | 2.189 / 10.783 | 3.312 / 12.893 | 3.312 / 12.893 |
| 5%（溢价） | 3.371 / 17.272 | 13.859 / 24.150 | 5.248 / 18.089 |

以 Varied 为基准：

| 票息 | Reference 平均/最大 | Ref-4 平均/最大 |
|---:|---:|---:|
| 1% | 1.731 / 3.649 | 1.762 / 2.746 |
| 3% | 1.126 / 4.813 | 1.126 / 4.813 |
| 5% | 10.503 / 16.474 | 4.041 / 7.217 |

要点：

- **5% 溢价债是 Reference 的重灾区**：它给出固定的 4.6667%，完全忽略资本损失，平均高估 10.5bp，最大 16.5bp。
- Ref-4 在 5% 票息下把误差压到 4.04bp，优势明显。
- 3% 平价时两个闭式公式完全相同（修正因子为 1），误差主要来自被忽略的 t 效应，最大约 4.8bp。
- 1% 折价时两者接近（1.73 vs 1.76bp），Ref-4 在部分长期限、高 t 的场景会略有过冲。

### 5.5 最大误差样本

| 指标 | 频率 | 期限 | t 档 | 票息 | 差值 (bp) |
|---|---|---|---:|---:|---:|
| IRR − Varied | 年付 | 短期 | 0.1 | 5% | −17.272 |
| IRR − Reference | 年付 | 短期 | 0.1 | 5% | −24.150 |
| IRR − Ref-4 | 年付 | 短期 | 0.1 | 5% | −18.089 |

三个指标的最坏样本完全重合：**年付、2 年短债、t≈0.1、5% 高票息**。这是"首期税基残差 + 高票息 + 短久期"共同作用的压力角。

## 7. 结论与建议

### 7.1 算法定位

| 算法 | 性质 | 适用场景 |
|---|---|---|
| IRR | 数值精确解；恒定票息、税后 IRR 打平 | 需要"真实恒定票息应税债"的等效收益率；交易/估值主值 |
| Varied | 数值精确解；税后现金流完全复制 | 需要严格的税后现金流等价；校验其他算法的基准 |
| Reference | 闭式近似；忽略 t、n、折溢价 | 平价附近、t≈1 的心算/速算 |
| Ref-4 | 闭式近似；含 n 与票息修正 | 需要闭式解且对精度有要求时的首选 |

### 7.2 选择建议

1. **精度优先**：用 IRR 或 Varied 数值解。t 接近 1 时两者无差别；t 远离 1 时先明确"等价"的定义，再选择对应算法。
2. **闭式解优先**：选 **Ref-4**。它相对 Varied 平均 2.31bp、最大 7.22bp，整体约为 Reference 的一半误差；在 5% 高票息场景优势最大。
3. **只用 Reference 的场景**：票息接近 YTM（平价）、t 接近 1、且能接受几个 bp 的误差。不要把它用于 5% 高票息、短久期、t 远离 1 的组合。
4. **当前工具**：`ytm_before_tax_ifind.py` 的主值用 IRR，参考值用 Reference。若希望参考值更稳，可把参考值切换为 Ref-4（代码已实现 `reference_yield_formula4`，只是 GUI 未调用）。

### 7.3 误差的量级记忆

- t≈0.9：IRR−Varied 几乎为 0（≤0.1bp）；闭式解仍受票息影响，Reference 最坏约 16bp。
- t≈0.5：IRR−Varied 约 1.4bp；Reference / Ref-4 平均约 6.4 / 3.7bp，最坏约 17 / 10bp。
- t≈0.1：IRR−Varied 约 5bp；Reference 最坏 24bp，Ref-4 最坏 18bp（均相对 IRR）。
- 5% 票息：Reference 的误差约是 1%–3% 票息的 4–7 倍。

```bash
# 在仓库根目录执行

```

脚本会输出明细表、三张差异矩阵、总体汇总和按 t 分档汇总。本报告中的图片由同一份 `build_rows()` 数据生成。

### C. 局限与注意事项

1. **合成样本**：样本是人为构造的规则债券，不是真实市场存量券；结论反映的是算法性质，不是某个交易日的市场统计。
2. **税率固定 25%**：未考虑不同投资者、不同券种的税率差异。
3. **税收假设**：沿用文档设定——买入前的应计利息部分免税（成本收回），仅对买入后产生的利息缴税；首期税基按 \(t\) 分摊。
4. **未考虑资本利得税、信用风险、流动性溢价、融资成本**。
5. **t 维度的实现方式**：在同一计息期内移动交割日，因此剩余期限会随 t 在一个付息期内变化（明细表已列出）；期限档与 \(n\) 不变，但严格来说 t 效应与剩余期限效应并未完全解耦。
6. **n=1 未覆盖**：所有样本 \(n\ge2\)，未触发 CFETS 最后付息周期的 ACT_365L 单利分支；该分支下 IRR/Varied 与文档的复利公式会有 0.5–1.8bp 的额外差异。
7. **Ref-4 的年化方式**：代码按"每期计算后 ×f"年化，对应文档图 (4) 的按付息期口径；若直接按年化 \(c,r,n\) 代入，数值会略有不同。
