
# 现金流相同的虚拟债券
我在[国债还原税前收益率速算公式](https://zhuanlan.zhihu.com/p/106650552) （以下简称《速算公式》）中提出了一个不免税的**虚拟债券**与免税国债的**等价方程**。

核心思想是：若**虚拟债券的税后现金流和国债一样**，则它们等价。

| 符号    | 含义                                                                        |
| ----- | ------------------------------------------------------------------------- |
| $f$   | 每年付息次数                                                                    |
| $c$   | 票面利率 / $f$                                                                |
| $r$   | 国债到期收益率 / $f$                                                             |
| $y$   | 待求的税前到期收益率 / $f$                                                          |
| $T$   | 税率                                                                        |
| $n$   | 剩余付息次数                                                                    |
| $t$   | $\dfrac{\text{下一付息日}-\text{当前}}{\text{下一付息日}-\text{上一付息日}}$，$0\le t\le 1$ |
| $P_0$ | 国债当前的全价                                                                   |

第一期现金流有残差，买入之前的票息不用交所得税（该部分是买入时已支付应计利息的成本收回，不计入买方当期应税利息），买入之后的票息要交所得税。设这只**虚拟债券**第一期的现金流为$x$，则需满足 $x(1-t)+xt(1-T)=c$ ，于是 $x=\frac{c}{1-tT}$ 

虚拟债券未来现金流折现为国债全价：

$$
P_{0}=\frac{c/(1-tT)}{(1+y)^t}+\frac{c/(1-T)}{(1+y)^{t+1}}+...+\frac{c/(1-T)}{(1+y)^{t+n-1}}+\frac{1}{(1+y)^{t+n-1}}
$$
容易求出 税前到期收益率$y$

但是，这里的虚拟债券的首期现金流 $c/(1-tT)$ 和后续的现金流 $c/(1-T)$ 不一样，现实中**不存在**这种债券。

因此，我们要换一个思路，假设**虚拟债券和国债的IRR相同**。
# IRR相同的虚拟债券

## 第一步：确定恒定票息 $K$

设虚拟债券的票息为恒定的$K$。在**同一个全价** $P_0$ 下，**税后 IRR 等于国债的** $r$。

第一期现金流有残差，买入之前的票息不用交所得税（因为该部分票息实际上归属于卖方），买入之后的票息要交所得税。这只**虚拟债券**第一期的现金流为 $K(1-t)+Kt(1-T)=K(1-tT)$ 
$$
P_0=\frac{K\,(1-tT)}{(1+r)^{t}}+\sum_{k=1}^{n-1}\frac{K\,(1-T)}{(1+r)^{t+k}}+\frac{1}{(1+r)^{t+n-1}}
\tag{1}
$$

## 第二步：求税前到期收益率 $y$

同一只债券、同一个价格，换成税前现金流贴现：

$$
P_0=\sum_{k=0}^{n-1}\frac{K}{(1+y)^{t+k}}+\frac{1}{(1+y)^{t+n-1}}
\tag{2}
$$

由$(1)$ 解出 $K$ 后代入 $(2)$ 可解出 $y$。

## 第一步的闭式解

$(1)$ 可直接解出 $K$，无需数值迭代。记

$$
v=\frac{1}{1+r},\qquad A=\sum_{k=0}^{n-1}v^{\,t+k}
\tag{3}
$$

AI 推导出：

$$
\boxed{\;K=\frac{c\,A}{(1-T)A+T(1-t)\,v^{t}}\;}
\tag{4}
$$

### 性质

- $T=0$ 时 $K=c$（无税，无需放大）。
- $t=1$ 时 $K=\dfrac{c}{1-T}$，即《速算公式》中的"超简便公式"的票息口径。
- 一般地 $\dfrac{c}{1-tT}\le K\le \dfrac{c}{1-T}$：恒定票息落在"首期票息"与"其余各期票息"之间，$t$ 越大越靠近上界。

# 与《速算公式》一文的对比

《速算公式》构造的虚拟债券**逐期对齐税后现金流**（每期税后现金流都等于 $c$），因此票息是时变的，整个问题只剩 $y$ 一个未知数，是一元方程：

$$
P_0=\frac{\,c/(1-tT)\,}{(1+y)^{t}}+\sum_{k=1}^{n-1}\frac{\,c/(1-T)\,}{(1+y)^{t+k}}+\frac{1}{(1+y)^{t+n-1}}
\tag{5}
$$
本文构造的虚拟债券票息是恒定不变的，通过IRR与国债等价。

两者结构差异：

|           | 《速算公式》                                        | 本文             |
| --------- | --------------------------------------------- | -------------- |
| 对齐层级      | 逐期现金流                                         | 仅 IRR          |
| 票息形状      | 时变：$z_0=\dfrac{c}{1-tT}$，$z_k=\dfrac{c}{1-T}$ | 恒定：$K$         |
| 税后现金流     | 与国债完全相同 $(c,c,\dots,c)$                       | 与国债不同，仅 IRR 相同 |
