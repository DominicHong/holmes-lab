
上一次说到国债的免税效应巨大，那么投资时如何把国债这些免税资产和不免税的资产拉到同一起跑线一起比较呢？固定收益资产一般比较的是到期收益率YTM。某只国债到期收益率为 r，那么如果不投资该国债而投资其他不免税的资产，需要达到到期收益率y 才能与该国债的r 等价，显然y需要比r更大，具体是什么关系呢？

### 困难

YTM的计算公式是高次多项式，这种方程没有代数解，只能用数值法逼近。我们现在是21世纪，用Excel算一下当然是秒出结果。但是交易员都是有情怀的人，喜欢手持计算器啪啪啪地按键计算，更有触感（实际原因是屏幕空间不足够放Excel，即使是四屏也不够）。

所以，现在需要得到一条近似的简便公式，方便手持计算器计算，最好足够短，啪啪啪的次数不会太多。

然而这个简单朴素的要求，却困扰了我整个职业生涯。如果是以净价100元交易的国债，YTM=票面利率c，那么很容易推导出 y = r / (1-T)，其中T为税率。但是如果是折价或者溢价交易，而国债只有票面利息部分免税，那么公式就会复杂。我在年轻时动用了大量脑细胞，用小学生的思维苦心想出了一个超朴素超简便的公式。

### 超朴素超简便公式

承接上文，假设以净价100元交易，国债票面利率为c，到期收益率r = c，那么 y = c / (1-T)，y - c = cT / (1-T)，就是说y和c之间的差值就是cT/(1-T)。那么当折价或溢价交易时，只有票面利息c这部分免税，可能y和r的差值也大概是cT/(1-T)？在这种朴素天真烂漫的美好想象之下，得到**超简便公式(1)**：

### 方程求解

P 为债券的现值，其中$P_0$为国债的现值，$P_y$为不免税资产的现值

c 为债券的票面利率

r 为国债的到期收益率

T 为税率

n 为剩余付息次数

t 为当前到下一个付息日的天数与上一付息日和下一付息日之间的天数之比，显然 t 永远 <= 1

我们的目标是求**不免税资产的到期收益率**，设为y

对于国债，未来现金流折现为全价：

$$
P_{0}=\frac{c}{(1+r)^t}+\frac{c}{(1+r)^{t+1}}+...+\frac{c}{(1+r)^{t+n-1}}+\frac{1}{(1+r)^{t+n-1}}
$$

对于不免税资产，我们构造一只**虚拟债券**，使得它的税后现金流和上面的国债一样。

第一期现金流有残差，买入之前的票息不用交税，买入之后的票息要交税，设这只**虚拟债券**第一期的现金流为x，则需满足 $x(1-t)+xt(1-T)=c$ ，于是 $x=\frac{c}{1-tT}$ 

虚拟债券未来现金流折现为全价：

$$
P_{y}=\frac{c/(1-tT)}{(1+y)^t}+\frac{c/(1-T)}{(1+y)^{t+1}}+...+\frac{c/(1-T)}{(1+y)^{t+n-1}}+\frac{1}{(1+y)^{t+n-1}}
$$


注意，这种**虚拟债券**在现实中不可能存在，因为它首期的票面利息和往后n期的票面利息不一样。如果要构造一只现实中可能存在的虚拟债券，即每期的票面利息一样，则非常麻烦，因为还需要考虑免税的折现，在这里就不深入探讨了。

国债和虚拟债券的全价现值应相等，于是有$P_0=P_y$，可用数值法求出y

如果要求代数解，则需要以下两个**近似式**：

​       当n取值比较小（即使是10年国债，n <= 10），x取值也比较小时（收益率一般在2%-5%之间），

​       粗略点可以令  (1 + x)^n 约等于 1 + nx； 

​       精确一点可以令 (1 + x)^n 约等于 1 + nx + (n(n-1)/2)x

### 回归修正

一般来说，回归分析用于在未知规律的情况下，强行通过统计数据拟合，无中生有出一个函数。本问题中我们已经知道背后的函数，只是无法得出代数解，正确的解决方法是用数值法解方程，而不是用回归分析。不过现实世界中，债券的票面利率、到期收益率和剩余期限的组合有限，在样本有限的情况下，回归拟合不失为一个可尝试的办法。下面我们就尝试通过回归分析修正**一次简式(4)** 与**超简便公式(1)**，使其更接近真实结果。

上述两式都未考虑t的影响（再重温一次，t为当前到下一个付息日的天数与上一付息日和下一付息日之间的天数之比），所以我们使用虚拟的很多个债券样本，对 y = f(t) 做一元线性回归。

Fixed Income的世界中，**万物皆现金流**，债券也是现金流的一种。我们使用的虚拟债券样本用以下规则生成：

票面利率 c 取值范围为【2.0%， 4.0%】，步长0.2%，一共取11个值

剩余期限 n 取值范围为【3年， 5年】，步长0.2年，一共取11个值

到期收益率 r 取值范围为【3年， 5年】，步长0.2年，一共取11个值

一共生成1331个样本。

### 你以为这就完了吗？并没有……

我们还可以摒弃一切推理，粗暴地用线性回归直接求函数。

国债税前收益率y是关于到期收益率 r ，票面利率 c 以及剩余期限 n 的函数，即：y = f(r,c,n)

#### 虚拟数据的回归

基于实际情况，我们使 r 从2%开始，每隔0.01%取一个值一直到4%共201个值，使 c 从2%开始，每隔0.01%取一个值一直到4%共201个值，使 n 从3年开始，每隔0.01取一个值一直到5年共201个值：

r=2%，2.01%，2.02%……3.99%，4%
c=2%，2.01%，2.02%……3.99%，4%
n=3年， 3.01， 3.02…… 4.99， 5年
三者排列共得到8,120,601个样本，使用这些样本计算出税前收益率y的取值，并对y = f（r,c,n）进行多元线性回归。

得到的结果为：

**y=1.064635r+0.388998c-0.0562n** ， 误差绝对值的均值为7bp。

#### 实际数据的回归

采用2019年9月12日市场上存续的国债数据，挑选其中剩余期限大于1年的国债，对这些国债进行税前收益率计算并回归，得到的结果为： 

**y=1.020047r+0.368751c-0.0086n**， 误差绝对值的均值为13bp。

筛选上述存续国债中剩余期限在1-10年的国债，进行回归得到的结果为：

**y=1.083939r+0.381493c-0.0589n**，误差绝对值的均值为12bp。

样本可以按需生成，想要多少有多少，回归结果也能有无数个，可以随便玩。
