# 一、现金流相同的虚拟债券
我在[国债还原税前收益率速算公式](https://zhuanlan.zhihu.com/p/106650552) （以下简称《速算公式》）中提出了一个不免税的**虚拟债券**与免税国债的**等价方程**。

核心思想是：若**虚拟债券的税后现金流和国债一样**，则它们等价。

| 符号    | 含义                                                                       |
| ----- | ------------------------------------------------------------------------ |
| $f$   | 每年付息次数                                                                   |
| $c$   | 票面利率 / $f$                                                               |
| $r$   | 国债到期收益率 / $f$                                                            |
| $y$   | 待求的税前到期收益率 / $f$                                                         |
| $T$   | 税率                                                                       |
| $n$   | 剩余付息次数                                                                   |
| $t$   | $\frac{\text{下一付息日}-\text{当前}}{\text{下一付息日}-\text{上一付息日}}$，$0\le t\le 1$ |
| $P_0$ | 国债当前的全价                                                                  |

第一期现金流有残差，买入之前的票息不用交所得税（该部分是买入时已支付应计利息的成本收回，不计入买方当期应税利息），买入之后的票息要交所得税。设这只**虚拟债券**第一期的现金流为$x$，则需满足 $x(1-t)+xt(1-T)=c$ ，于是 $x=\frac{c}{1-tT}$ 

虚拟债券未来现金流折现为国债全价：

$$
P_{0}=\frac{c/(1-tT)}{(1+y)^t}+\frac{c/(1-T)}{(1+y)^{t+1}}+...+\frac{c/(1-T)}{(1+y)^{t+n-1}}+\frac{1}{(1+y)^{t+n-1}}
$$
容易求出 税前到期收益率$y$

但是，这里的虚拟债券的首期现金流 $c/(1-tT)$ 和后续的现金流 $c/(1-T)$ 不一样，现实中**不存在**这种债券。

因此，我们要换一个思路，假设**虚拟债券和国债的IRR相同**。
# 二、IRR相同的虚拟债券

## 第一步：确定恒定票息 $K$

设虚拟债券的票息为恒定的$K$。在**同一个全价** $P_0$ 下，**税后 IRR 等于国债的** $r$。

第一期现金流有差异，买入之前的票息不用交所得税（因为该部分票息实际上归属于卖方），买入之后的票息要交所得税。这只**虚拟债券**第一期的现金流为 $K(1-t)+Kt(1-T)=K(1-tT)$ 
$$
P_0=\frac{K\,(1-tT)}{(1+r)^{t}}+\sum_{k=1}^{n-1}\frac{K\,(1-T)}{(1+r)^{t+k}}+\frac{1}{(1+r)^{t+n-1}}
\tag{1}
$$

## 第二步：求税前到期收益率 $y$

同一只债券、同一个价格，换成税前现金流贴现：

$$
P_0=\sum_{k=0}^{n-1}\frac{K}{(1+y)^{t+k}}+\frac{1}{(1+y)^{t+n-1}}
\tag{2}
$$

由$(1)$ 解出 $K$ 后代入 $(2)$ 可解出 $y$。

## 第一步的闭式解

$(1)$ 可直接解出 $K$，无需数值迭代。记

$$
v=\frac{1}{1+r},\qquad A=\sum_{k=0}^{n-1}v^{\,t+k}
$$

AI 推导出：

$$
\boxed{\;K=\frac{c\,A}{(1-T)A+T(1-t)\,v^{t}}\;}
$$

### 性质

- $T=0$ 时 $K=c$（无税，无需放大）。
- $t=1$ 时 $K=\dfrac{c}{1-T}$，即《速算公式》中的"超简便公式"的票息口径。
- 一般地 $\dfrac{c}{1-tT}\le K\le \dfrac{c}{1-T}$：恒定票息落在"首期票息"与"其余各期票息"之间，$t$ 越大越靠近上界。

# 三、与《速算公式》一文的对比

《速算公式》构造的虚拟债券**逐期对齐税后现金流**（每期税后现金流都等于 $c$），因此票息是时变的，整个问题只剩 $y$ 一个未知数，是一元方程：

$$
P_0=\frac{\,c/(1-tT)\,}{(1+y)^{t}}+\sum_{k=1}^{n-1}\frac{\,c/(1-T)\,}{(1+y)^{t+k}}+\frac{1}{(1+y)^{t+n-1}}
$$
本文构造的虚拟债券票息是恒定不变的，通过IRR与国债等价。

两者结构差异：

|       | 《速算公式》                                        | 本文             |
| ----- | --------------------------------------------- | -------------- |
| 对齐层级  | 逐期现金流                                         | 仅 IRR          |
| 票息形状  | 时变：$z_0=\dfrac{c}{1-tT}$，$z_k=\dfrac{c}{1-T}$ | 恒定：$K$         |
| 税后现金流 | 与国债完全相同 $(c,c,\dots,c)$                       | 与国债不同，仅 IRR 相同 |

## 各算法对比
《速算公式》一文提出了一个超简便速算公式：
$$
y=r+\frac{cT}{1-T}
\tag{3}
$$
以及一个更精确的速算式：
$$
y=r+\frac{\frac{1}{n}+r}{\frac{1}{n}+c}*\frac{cT}{1-T}
\tag{4}
$$

我们将其设为参考值，将IRR法算出来的$y$称作IRR，将时变票息法算出来的$y$称作Varied，对比它们与(3)(4)之间的差异。以下称(3)为Ref，(4)为Ref-4

样本共54只虚拟国债，国债YTM统一为3%

| 维度          | 取值                              |
| ----------- | ------------------------------- |
| 付息频率        | 年付、半年付                          |
| t           | 0.1, 0.5, 0.9                   |
| 原始期限        | 2 年（短期）、5 年（中期）、10 年（长期）        |
| 剩余期限（因t的不同） | 1.05-1.90、 4.05-4.90、 9.05-9.90 |
| 票面利率        | 1%（低）、3%（平）、5%（高）               |

## 总体对比
以下差值单位均为BP
### 以IRR为基准

| 比较              | 平均绝对差 | 最大绝对差 |
| --------------- | ----: | ----: |
| IRR − Varied    |  2.12 | 17.27 |
| IRR − Reference |  6.35 | 24.15 |
| IRR − Ref-4     |  3.71 | 18.09 |

### 以Vaired为基准
Ref 与 Ref-4 的设计目标是逼近Varied 解，因此下表更能反映两个闭式公式的内在精度：

| 比较                 | 平均绝对差 |  最大绝对差 |
| ------------------ | ----: | -----: |
| Varied − Reference | 4.453 | 16.474 |
| Varied − Ref-4     | 2.310 |  7.217 |

Ref-4 显然比Ref 准得多

## 按 t 分档

| t 档 | IRR−Varied 平均/最大 | IRR−Ref 平均/最大 | IRR−Ref-4 平均/最大 |
| --- | ---------------: | ------------: | --------------: |
| 0.1 |     4.95 / 17.27 |  8.42 / 24.15 |    5.52 / 18.09 |
| 0.5 |      1.37 / 4.37 |  6.38 / 17.35 |    3.65 / 10.29 |
| 0.9 |      0.04 / 0.10 |  4.24 / 16.05 |     1.95 / 6.69 |

- IRR−Varied 随 t 减小而显著放大：t=0.9 时几乎为 0，t=0.1 时平均接近 5bp。这与**t→1 时两种构造重合**的理论一致。
- Ref 与 Ref-4 对 t 的敏感度较低（它们要么完全忽略 t，要么只通过 n 间接处理），因此误差主要由票息/折溢价驱动。

## 按付息频率

| 频率  | IRR−Varied 平均/最大 | IRR−Ref 平均/最大 | IRR−Ref-4 平均/最大 |
| --- | ---------------: | ------------: | --------------: |
| 年付  |     2.52 / 17.27 |  7.16 / 24.15 |    4.17 / 18.09 |
| 半年付 |     1.72 / 12.86 |  5.54 / 17.19 |    3.24 / 12.54 |

年付样本的误差普遍大于半年付：年付的付息次数少、单期现金流大，首期税基残差占整只债券现金流的比例更高。

## 按期限

| 期限档     | IRR−Varied 平均/最大 | IRR−Ref 平均/最大 | IRR−Ref-4 平均/最大 |
| ------- | ---------------: | ------------: | --------------: |
| 短期（2Y）  |     3.93 / 17.27 |  7.15 / 24.15 |    5.67 / 18.09 |
| 中期（5Y）  |      1.64 / 7.52 |  5.02 / 16.31 |     2.26 / 5.58 |
| 长期（10Y） |      0.79 / 3.51 |  6.88 / 18.55 |     3.19 / 6.69 |

短债对 t 最敏感：首期在全部现金流中的占比最高，t 的处理方式直接决定结果。长债的 IRR−Varied 很小，但 Ref 仍因忽略折溢价而保持约 6.9bp 的平均误差。
## 按折溢价

|     票息 | IRR−Varied 平均/最大 | IRR−Ref 平均/最大 | IRR−Ref-4 平均/最大 |
| -----: | ---------------: | ------------: | --------------: |
| 1%（折价） |      0.80 / 3.74 |   1.87 / 3.75 |     2.56 / 5.05 |
| 3%（平价） |     2.19 / 10.78 |  3.31 / 12.89 |    3.31 / 12.89 |
| 5%（溢价） |     3.37 / 17.27 | 13.86 / 24.15 |    5.25 / 18.09 |

- **5% 溢价债是 Ref 的重灾区**：它给出固定的 4.6667%，完全忽略资本损失，平均高估 14bp，最大 24bp。
- Ref-4 在 5% 票息下把误差压到 4bp，优势明显。
- 3% 平价时两个闭式公式完全相同（修正因子为 1），误差主要来自被忽略的 t 效应。
- 1% 折价时两者接近（1.87 vs 2.56bp），Ref-4 在部分长期限、高 t 的场景会略有过冲。

## 最大误差样本

| 指标              | 频率  | 期限  | t 档 |  票息 | 差值 (bp) |
| --------------- | --- | --- | --: | --: | ------: |
| IRR − Varied    | 年付  | 短期  | 0.1 |  5% | −17.272 |
| IRR − Reference | 年付  | 短期  | 0.1 |  5% | −24.150 |
| IRR − Ref-4     | 年付  | 短期  | 0.1 |  5% | −18.089 |

三个算法的最坏样本完全重合：**年付、2 年短债、t≈0.1、5% 高票息（折价）**。

# 总结
## 算法定位

| 算法     | 性质                   | 适用场景                   |
| ------ | -------------------- | ---------------------- |
| IRR    | 数值迭代解；恒定票息、税后 IRR 打平 | 最精确的算法                 |
| Varied | 数值迭代解；税后现金流完全复制      | 需要严格的税后现金流等价；校验其他算法的基准 |
| Ref    | 闭式近似；忽略 t、n、折溢价      | 平价附近、t≈1 的心算/速算        |
| Ref-4  | 闭式近似；含 n 与票息修正       | 需要闭式解且对精度有要求时的首选       |

现在的AI数学能力超群，我问它有没有比 Ref 和 Ref-4 更精确的闭式解，它二话不说就用二阶泰勒展开一通硬算，再结合统计学给出 Magic Number 修正参数，精确度可以达到零点几BP。

但是我一看它那长长的纠缠不休的式子，叹了一口气。

**AI的简单答案，对于人类是天书。**

还是老老实实用程序解吧。
